## 📄 重要论文

- **Your Transformer Can Hold Two Thoughts at Once（线性叠加假设）**：论文证明当不同文本流的输入被线性组合时，模型输出是各自 next-token 分布的叠加，且叠加性是 Transformer 架构的内在属性而非训练涌现。
  - 重要性：★★★★★ / 5
  - 核心价值：为激活操控与多任务干预提供理论依据
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.29845)

- **Rufus-Air：开放可复现的 LLM 后训练配方**：在 GLM-4.5-Air-Base（106B-A12B）上给出八阶段串行流水线（SFT → Reasoning RL → Coding RL → 指令遵循 RL → 通用/编码/搜索 Agent → RLHF），完整公开数据、奖励设计与基础设施。
  - 重要性：★★★★★ / 5
  - 核心价值：少见的全流程后训练复现指南，可直接照搬
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.29421)

- **AgentKernel：信任原生的 Agent 操作系统**：论文主张当前治理栈只是应用层中间件、与 agent 共享进程信任边界，需要把信任边界下沉到操作系统层，隔离不可信输入、长期记忆与特权工具调用。
  - 重要性：★★★★★ / 5
  - 核心价值：为 agent 安全架构提供了 OS 级设计范式
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.29647)

- **Learning to Discover Interesting Mathematics**：定义定理的"内在有趣度"为证明长度与陈述长度之比，用于筛选 LLM 生成的海量数学结果中真正有价值的部分。
  - 重要性：★★★★★ / 5
  - 核心价值：解决 LLM 数学发现"数量爆炸、价值稀疏"的筛选难题
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.28603)

- **Capable yet Parsimonious：提取前沿模型的隐藏 CoT**：通过注册自定义工具诱导闭源前沿模型外化中间推理，并在开源模型上与原生 CoT 对比验证其真实性。
  - 重要性：★★★★★ / 5
  - 核心价值：为闭源模型推理透明度提供可操作的探测手段

- **ExplorationBench：在可验证的"外星世界"中测量 AI 探索能力**：设计全新可验证环境，区分系统是真正通过探索发现假设，还是从预训练数据中回忆了相关知识。
