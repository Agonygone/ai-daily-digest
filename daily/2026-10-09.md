- **NVIDIA PivotOPD：教多轮 Agent 从关键错误中恢复**：提出 on-policy 蒸馏方法，训练多轮 LLM Agent 避免早期关键错误并从中恢复，在 3 个 Agent benchmark 上对 13 个基线取得最佳平均成绩。

- **Real Long-Term Memory for AI：5000 万 token 窗口，比重新计算更快更便宜**：提出 galahad-kv 记忆层，将每约 16,000 token 块的 KV 状态字节精确保存至加密本地 NVMe 磁盘，后续加载无需重计算。在单张 H100 上以 vLLM 处理 5000 万 token 真实文本验证。
  - 重要性：★★★★★ / 5
  - 核心价值：KV 缓存持久化方案，长上下文成本大幅下降
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.10845)

- **Self-Retrospection Distillation：将事后经验转化为事前预见**：针对 RLVR 中 group-relative 目标在全部 rollout 获得相同奖励时信号消失的问题，提出让 Agent 从轨迹中学习"本应预见什么"的蒸馏方法。
  - 重要性：★★★★★ / 5
  - 核心价值：解决 RLVR 奖励稀疏问题，提升训练信号利用率
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.08077)

- **RoboJEPA：规模化机器人潜在世界模型**：基于 JEPA 架构，在覆盖 12 种机器人形态的大规模数据集上训练，首次系统研究世界模型能力随模型规模、数据和算力的 scaling 规律。
  - 重要性：★★★★★ / 5
  - 核心价值：机器人世界模型 scaling law 首次系统验证
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2610.10515)

- **Long-WAM：扩展世界-动作模型的上下文**：核心发现是"能访问历史不等于会使用历史"——更长的历史只有在视频基础模型以自回归方式预训练时才有显著收益。提出在实时控制约束下扩展因果世界-动作模型上下文的模型-系统框架。
  - 重要性：★★★★★ / 5
  - 核心价值：机器人实时控制中历史信息利用的关键条件
  - 来源：[arXiv](https://arxiv.org/abs/2610.10528v1)

- **Rephrase Before You Act：VLA 模型的语言敏感性**：揭示 VLA 模型对指令措辞极度敏感——一词之差可导致成功率变化数十个百分点（如 π₀.₅ 对"打开炉子"100% 成功，对"打开热板"仅 2%），且这种敏感性不继承自底层 VLM。

- **Agent Plasticity：通过经验衡量自我改进**：提出评估 Agent 自我改进能力的三维框架——未来表现是否提升并泛化、新能力获取效率、自我改进过程何处断裂。
