## 📄 重要论文

- **WhiteMatter：通过 KV Source Mixing 实现全连接跨层注意力**：允许 Transformer 每一层从任意深度的历史 token 表示中读取信息，用可学习 mixer 为当前上下文选择最有用的深度并合并进共享 KV 缓存，打破同层深度限制。
  - 重要性：★★★★★ / 5
  - 核心价值：跨层信息复用，为长上下文与推理效率提供新架构方向
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.18486)

- **Telescopic Language Models：一个模型覆盖全部算力预算**：用随机前缀监督加全容量锚点训练嵌套容量的 Transformer，每次训练一个随机截断的前缀容量轴与一次全容量前向，使单一训练产物在多个算力预算下都是有效语言模型。
  - 重要性：★★★★★ / 5
  - 核心价值：告别"每个预算训一个模型"，弹性推理一次训练搞定
  - 来源：[arXiv](https://arxiv.org/abs/2609.35769v1)

- **How to Loop MoE：Flatten the Experts, Untie the Attention（Foil）**：回答"如何循环 MoE"的问题，通过展平专家并解绑注意力，在固定专家参数与每 token 专家算力下实现循环复用，提升 MoE 的参数利用率。
  - 重要性：★★★★★ / 5
  - 核心价值：循环 Transformer 与 MoE 结合的具体设计法则
  - 来源：[arXiv](https://arxiv.org/abs/2609.35751v1)

- **在预训练 LLM 中近似 Softmax：模型敏感性与内核加速**：在 B200 上张量核吞吐比特殊函数指数吞吐高两个数量级以上，作者在 10 个冻结解码器模型（0.5B–72B）上系统刻画预训练模型对 softmax 精度的真实需求。
  - 重要性：★★★★★ / 5
  - 核心价值：注意力内核可安全近似 softmax，推理加速空间明确
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33586)

- **Self-Play Search Distillation（SPSD）：用 MuZero 式自对弈生成超人推理数据**：在棋类游戏上训练类 MuZero 网络自对弈，利用可执行环境把搜索转化为结构化推理数据，缓解 LLM 推理训练中合成数据质量低、人工标注昂贵的问题。
  - 重要性：★★★★★ / 5
  - 核心价值：可执行环境+自对弈成为高质量推理数据的新来源
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.30936)

- **Selecting Diverse SFT Traces Improves Post-RL Generalization**：研究 SFT 数据的"路径多样性"（推理步骤序列的差异），提出轻量规则式指纹来筛选多样性，同一数据池与预算下，选多样路径比选相似路径显著提升 RL 后的问题覆盖率。
  - 重要性：★★★★★ / 5
  - 核心价值：SFT 数据筛选新维度，直接提升 RL 后泛化
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33780)

- **Do We Really Need KL Divergence for On-Policy Distillation?**：发现在 on-policy distillation 中，只要保持更新方向指向教师，KL 散度并非必需，为 OPD 损失函数设计松绑。
  - 重要性：★★★★★ / 5
  - 核心价值：蒸馏损失可简化，降低实现与调参复杂度
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33791)

- **Distillation Defenses Easily Break After Reinforcement Learning**：现有防蒸馏攻击的防御通常在蒸馏后立即评估，隐含假设攻击者不再继续训练；本文证明攻击者一旦继续做 RL，防御即被轻易击破。
  - 重要性：★★★★★ / 5
  - 核心价值：闭源模型防蒸馏策略需要重新设计评估协议
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35699)

- **DISCO：分布式长上下文扩展与"接地理-推理"解耦**：指出长上下文推理质量崩塌（context rot）源于单体架构中接地搜索负担耗尽推理所需表示容量，提出将 grounding 与 reasoning 解耦的分布式扩展方案。
  - 重要性：★★★★★ / 5
  - 核心价值：为百万 token 上下文的推理质量崩塌提供结构性解法
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33485)

- **Hard Vision, Easy Vision：GPT-6 Astra 在计算机视觉上的能力边界**：在 34 项能力、55 个 benchmark、9 大 CV 领域上评估 GPT-6 Astra 与五个前沿通用系统，并与专用 CV 模型对比，刻画通用系统已覆盖与仍未攻克的视觉任务。
  - 重要性：★★★★★ / 5
  - 核心价值：CV 从业者判断哪些专用模型将被通用模型取代
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35718)

- **TokenCast：预测 LLM Agent 执行过程中的 token 消耗**：针对同一任务 token 消耗可跨数量级波动的痛点，学习可组合的成本模型，在执行前预测并在运行中持续修正总消耗。
  - 重要性：★★★★★ / 5
  - 核心价值：Agent 成本可预测，为预算控制与调度提供依据
  - 来源：[arXiv](https://arxiv.org/abs/2609.35760v1)

- **Relic：从多智能体协作到持久组织能力**：将反复出现的协作失败（如一个编码 Agent 改了接口、另一个仍在旧版本上开发）转化为组织所有、可执行的协议，使经验在参与者更替后仍能约束团队。
  - 重要性：★★★★★ / 5
  - 核心价值：多 Agent 协作经验可沉淀为可执行规范，而非一次性对话
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32965)

- **CineSubBench：用多语言电影字幕评测 LLM 的长篇叙事与文化理解**：构建基于多语言电影字幕的长上下文电影理解 benchmark，要求模型整合长篇叙事、跨语言解读并作出文化情境化的观众判断。
  - 重要性：★★★★★ / 5
  - 核心价值：填补长叙事+文化理解评测空白，区别于法律/医学等专业域
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36218)

- **LeRF：学习参考坐标系以进行视角采择推理**：针对 VLM 在需要从他人视角或想象观察者视角推理时默认退回相机视角的问题，提出学习参考坐标系的方法提升空间智能。
  - 重要性：★★★★★ / 5
  - 核心价值：VLM 空间推理的关键短板——视角采择被针对性解决
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.36219)
