## 📄 重要论文

- **WhiteMatter：通过 KV 源混合实现全连接跨层注意力**：让 Transformer 每一层都能调用任意深度的历史 token 表示，由学习到的 mixer 为当前上下文选择最有用的深度并合并进共享 KV 缓存，突破"每层只能用同深度表示"的限制。
  - 重要性：★★★★★ / 5
  - 核心价值：跨层信息复用新范式，可能改变 KV 缓存与深度设计
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.18486)

- **Telescopic Language Models：一个模型服务所有算力预算**：通过随机前缀监督加全容量锚点训练嵌套容量 Transformer，使单一训练产物在任意截断深度下都是合法语言模型，无需为每个算力点单独训练或压缩。
  - 重要性：★★★★★ / 5
  - 核心价值：一份权重覆盖多档推理成本，端侧到云端的部署范式
  - 来源：[arXiv](https://arxiv.org/abs/2609.35769v1)

- **Do We Really Need KL Divergence for On-Policy Distillation?**：研究发现 on-policy 蒸馏中 KL 散度并非必要，只要保持更新方向指向教师模型即可有效蒸馏，挑战了知识蒸馏的标准损失设计。
  - 重要性：★★★★★ / 5
  - 核心价值：简化 OPD 训练目标，降低后训练实现与调参成本
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33791)

- **DISCO：接地-推理解耦的分布式长上下文扩展**：针对"上下文腐化"现象，将上下文接地（grounding）的海量搜索负担与复杂推理所需的表征容量解耦，借鉴分布式计算思路提升百万 token 下的推理质量。
  - 重要性：★★★★★ / 5
  - 核心价值：直接针对长上下文推理质量塌陷，架构级解法
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33485)

- **How to Loop MoE：Foil 架构**：回答"如何循环 MoE"这一问题——在固定专家参数和每 token 专家计算量下，通过展平专家、解开注意力权重共享来实现循环复用，兼顾参数效率与专家利用率。
  - 重要性：★★★★★ / 5
  - 核心价值：循环 Transformer 与稀疏 MoE 的首次系统结合方案
  - 来源：[arXiv](https://arxiv.org/abs/2609.35751v1)

- **Hard Vision, Easy Vision：GPT-6 Astra 在计算机视觉上的能力边界**：在 34 项能力、55 个 benchmark、9 个 CV 领域上系统评估 GPT-6 Astra 与五个前沿通用系统，并与专用 CV 模型对比，刻画通用模型的视觉能力覆盖范围与仍难之处。
  - 重要性：★★★★★ / 5
  - 核心价值：CV 从业者判断哪些任务将被通用模型吞并的关键参考
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35718)

- **Distillation Defenses Easily Break After Reinforcement Learning**：现有蒸馏攻击防御通常在蒸馏后立即评估，隐含假设攻击者不再继续训练；本文证明攻击者在蒸馏后继续做 RL 训练即可轻易突破这些防御。
  - 重要性：★★★★★ / 5
  - 核心价值：现有防蒸馏方案的安全假设被证伪，需重新设计
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.35699)

- **Allspark：通过交替思维链实现弱到强迁移**：让小型弱模型学到的推理能力迁移到更大更强的模型，训练过程中完全不使用强模型的 rollout，大幅降低大规模 RL 实验的成本。
  - 重要性：★★★★★ / 5
  - 核心价值：用弱模型 rollout 训练强模型，RL 实验成本大幅下降
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.32913)

- **G²PTQ：用广义梯度补偿改进 LLM 训练后量化**：针对 GPTQ 类方法的两难——局部逐层目标缺乏全局监督，而全局目标固定 Hessian 估计、忽略一阶梯度导致指导逐渐失效——提出广义梯度补偿。
  - 重要性：★★★★★ / 5
  - 核心价值：PTQ 精度进一步提升，降低量化部署的精度损失
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.31009)

- **Nereus：LLM 后训练的自适应并行**：针对 RL 后训练中资源可用性、序列长度、内存压力和阶段瓶颈动态变化的问题，在模型共享 GPU 的前提下自动调整执行计划，避免初始方案随时间变得低效甚至不可行。
  - 重要性：★★★★★ / 5
  - 核心价值：长时 RL 训练不再因资源漂移而中断或降速
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.34645)

- **TokenCast：预测 LLM Agent 执行过程中的 token 消耗**：同一任务在不同运行间 token 消耗可相差一个数量级以上，TokenCast 学习可组合的成本模型，在任务执行前预测并在运行中持续修正。
  - 重要性：★★★★★ / 5
  - 核心价值：Agent 成本可预测，为计费、预算与调度提供依据
  - 来源：[arXiv](https://arxiv.org/abs/2609.35760v1)

- **KernelZero：提案者与编码者协同演化的 GPU Kernel 生成**：针对高质量训练数据稀缺与 kernel 正确性/性能权衡两大限制，用协同演化框架持续提升 GPU kernel 生成能力。
  - 重要性：★★★★★ / 5
  - 核心价值：自动生成高性能 GPU kernel，直接降低算子优化人力
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.33074)

- **NVAlign：连续自回归流匹配 TTS 中非语言控制的直接梯度优化**：填补连续自回归 flow-matching TTS 在非语言发声（笑声、叹息等）标签跟随方面缺乏后训练方法的空白。
  - 重要性：★★★★★ / 5
  - 核心价值：语音 Agent 的非语言表达可控性提升，情感更自然
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.31892)
