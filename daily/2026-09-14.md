## 📄 重要论文

- **Negative Self-Distillation：通过"避免缺陷"来学习推理**：研究指出 On-Policy Self-Distillation 在复杂推理任务上会严重退化，因为强迫学生模仿基于特权信息生成的"过度自信"推理轨迹会抑制探索；作者提出负向自蒸馏范式。
  - 重要性：★★★★★ / 5
  - 核心价值：修正主流自蒸馏范式，为推理模型后训练提供新方向
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11699)

- **An Open Recipe for IMO Gold：用 Nemotron 训练奥数证明模型**：从 Nemotron 3 Ultra 出发，用 SFT + RL 训练两个专家 checkpoint，并给出完全基于自然语言、无形式化证明器、无外部工具、无联网的测试时计算管线。
  - 重要性：★★★★★ / 5
  - 核心价值：开源可复现的奥数级推理配方，直接可用于推理模型训练
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10712)

- **T1：面向长时程任务的终端 Agent 强化学习**：122B MoE 模型在云沙箱真实 shell 中运行，单任务最多 300+ 次工具调用，以任务自带 verifier 作为奖励，并给出热启动稳定 actor-critic、稠密过程奖励等完整配方。
  - 重要性：★★★★★ / 5
  - 核心价值：终端 Agent RL 训练全流程开源，长时程任务落地有据可依
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11042)

- **NCP-ArchPreview：用"下一概念预测"迈向潜空间语言模型**：在标准 NTP 之外引入 Next Concept Prediction，通过乘积量化构建跨多 token 的离散概念词表，保留 token 级自回归生成能力。
  - 重要性：★★★★★ / 5
  - 核心价值：预训练目标层面的架构探索，或影响下一代 LLM 训练范式
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10715)

- **Beyond Solver Verdicts：面向自动形式化的生成式奖励模型**：形式化证明中求解器无法判断形式化翻译是否与参考形式化严格等价，作者将此漏洞定义为 Verdict-Preserving-Unfaithfulness（VPU）并证明纯结构性、仅看 verdict 的验证启发式在数学上是有界的。
  - 重要性：★★★★★ / 5
  - 核心价值：揭示神经符号系统的根本性验证盲区，形式化方向必读
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11085)

- **Memory as Plans（MaP-WAM）：以记忆为规划的世界-动作建模**：针对非马尔可夫的长时程操作任务，把记忆分解为"计划"，避免语言摘要丢失细粒度视觉证据，也避免视觉窗口在历史覆盖与执行效率间的取舍。
  - 重要性：★★★★★ / 5
  - 核心价值：机器人长时程记忆机制新解法，具身智能可直接借鉴
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11561)

- **SenseNova-U1.5：迈向原生统一视觉智能**：8B-MoT 原生统一多模态模型，无 encoder、无 VAE 架构，通过空间一致的 patch 重建强化视觉接口，原生支持最高 4K 分辨率。
  - 重要性：★★★★★ / 5
  - 核心价值：无编码器统一多模态架构落地，视觉生成与理解边界进一步融合
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11929)

- **PARSER：并行读取、深度推理的长上下文 Agent**：用一组绑定单 chunk 的轻量 subagent 并行读完整篇文档，再由 lead agent 迭代深度推理，将读取与推理解耦，消除对证据位置的敏感性并降低推理延迟。
  - 重要性：★★★★★ / 5
  - 核心价值：长文档 Agent 延迟与鲁棒性同时改善，RAG 架构可参考
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.06702)

- **Recursive Code World Models：用递归场景程序构建复杂世界**：从单张参考图出发，用递归场景程序（RSP）表示可执行世界，构造求解器递归调用自身重建复杂 3D 世界。
  - 重要性：★★★★★ / 5
  - 核心价值：代码化世界模型的可扩展构建路径，3D 生成与仿真受益
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11499)

- **HyQuant：面向 LLM 注意力机制的混合精度量化**：指出注意力模块在极低比特下误差显著，现有方法多依赖平滑处理离群值，作者提出混合量化设计以更好平衡精度与效率。
  - 重要性：★★★★★ / 5
  - 核心价值：低比特注意力量化的实用改进，推理成本可直接受益
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2608.27875)

- **IdeaAMBIG：基准测试研究想法中的"实现关键缺口"**：研究方法的"可编码就绪度"——是否提供足够信息让有能力的实现者或编码 agent 在不做无依据假设的前提下构建出目标方法。
  - 重要性：★★★★★ / 5
  - 核心价值：为 AI 科研自动化提供可度量的规格完备性基准
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.10539)

- **MetroLLM-Bench：把语言模型当作地铁自助终端运行时来评测**：955 个案例覆盖 6 个真实地铁系统（37–414 站）、11 类任务（路径规划、票价计算、故障、无障碍、对抗输入），模型须调用结构化工具并提交机器可渲染的终态。
  - 重要性：★★★★★ / 5

- **X-AuT：面向语音 LLM 的渐进式音频编码器压缩与跨尺度蒸馏**：直接删除整块会扰动解码器输入并导致漏字与提前 EOS，作者用短行为探针选择层组合，并通过表示对齐、跨尺度蒸馏、计划式学生策略监督与 LoRA 微调恢复性能。
  - 重要性：★★★★★ / 5
  - 核心价值：语音模型推理成本下降的可操作方案，避免删层常见退化
  - 来源：[HuggingFace Papers](https://huggingface.co/papers/2609.11412)

- **A Three-Layer Caching Architecture：商品级 CPU 上的低延迟 LLM 网页搜索**：开源答案引擎 OreoLook 用自动化浏览器 agent + 路由式 LLM 推理，本地搜索、缓存、会话管理与 embedding 栈全部跑在普通 CPU 硬件上。
  - 重要性：★★★★★ / 5
  - 核心价值：答案引擎的三层缓存设计可直接复用于低成本搜索产品
