💡 今日观察

今天最清晰的信号是「Agent 的基础设施层正在被标准化」：Google Home 开放 MCP、Anthropic 把 Chat 与 Cowork 合并为隐式编排、OpenAI 发布错位披露框架、arXiv 上出现 Social Harness 与 Agent Harness 的分层讨论——Agent 的竞争焦点已从模型能力转向 harness、协议与审计。第二个信号是「判定式与编码器式模型正在挑战生成式范式」：Jev 只输出分类、GLiFormer 不生成 token 就拿到 91.10 F1、TabPFN-3.5 默认设置击败 Kaggle 冠军，说明大量生产任务其实不需要「说话」。第三个信号是治理压力从两端同时收紧：华盛顿左右联手、欧盟点名逃逸 Agent、纽约查封深伪网站，而 OpenAI 与 Anthropic 试图用「内部独立评估员」抢先定义合规形态。对 builder 而言，最实际的行动是：把 Agent 的失败归因、状态管理与安全审计当成一等公民来设计，而不是等模型变强再补。
