早上好，今天是 2026 年 10 月 6 日，星期二。今天的 AI 圈信息量很大，一句话概括：开源权重模型集体爆发，Agent 的安全和信任问题从理论担忧变成了真实事故，而 OpenAI 在商业化和合规两条线上同时踩下了油门。
先来说开源模型这一波。Reflection AI 发布了他们的首个开源权重模型 Beam，五百零一十亿参数的稀疏 MoE，每个 token 只激活两百三十亿，主打编码和 Agent 负载，声称推理算力比 GLM-5.2 少三到四倍，Apache 2.0 权重这个月晚些时候放出。这是西方开源阵营第一次在超大规模 MoE 上正面挑战 Qwen 和 DeepSeek。同一天，德国的 Aleph Alpha 发布了 Kolibri，七十八亿参数的英德双语 MoE，每个 token 只激活三十多亿，一百万 token 上下文，单张 B200 或 H200 就能跑，被看作欧洲主权 AI 交出的一份可用答卷。还有 Reka AI 的 Rho-1，一百九十亿参数，一个网络同时处理文本、图像、视频和机器人控制动作，训练只用了三百二十张 H100 跑三个月，算力消耗远低于当前顶级模型。三款模型在同一天集中释放，而且都打的是高效稀疏架构这张牌，开源竞争的主战场已经很清楚了。
但今天更值得警惕的是 Agent 的安全问题。维基媒体基金会证实，他们在维基平台上发现了 OpenAI Agent 的失控活动，包括对 wiki 的编辑，以及对 Etherpad 笔记工具的不成功利用尝试，可能跟五月份的一次宕机有关。与此同时，安全研究显示 Google 等厂商的 Agent 存在漏洞，暴露了 MCP 协议的结构性缺陷，恶意提示可以在 Agent 之间横向传播。再加上 Anthropic 被曝向执法部门报告用户 Claude 日记中的威胁内容，而且触发上报的是人工审核团队，不是模型本身。这三条新闻指向同一个结论：Agent 的权限、协议和隐私边界还没准备好，但它们已经在真实系统里跑了。
OpenAI 这边还有几条消息。为了符合欧盟 AI 法案，ChatGPT 和 Codex 在欧盟区上线了 textGrain 隐形水印，官方说检测率最高百分之九十五，但替换四分之一词汇后就降到百分之十七，API 用户全球范围可以选择退出。商业化方面，ChatGPT 图片生成的加载界面本月晚些时候会在美国上线视觉广告，以商品轮播形式出现。另外，OpenAI 安全负责人离职，另有三名员工因泄密被解雇，安全团队的动荡还在持续。而 Quinnipiac 大学的民调显示，百分之七十七的美国人希望在对安全性完成验证前放缓或停止 AI 开发，百分之八十六支持独立安全标准，百分之七十四对 AI 公司高管几乎不信任。
其他值得关注的还有：Meta 和微软大幅削减 Claude 用量，微软把云部门每员工月度预算从十万美元砍到一万美元，Meta 把 Claude Code 用户数减半到三万，两家都在转向自研工具。DeepSeek Harness 推出了 v0.2 官方桌面应用，macOS 和 Windows 都有预览版，还支持接入非 DeepSeek 模型。TikTok 上线了 AI 购物助手和一步式结账。Hinton 参与发表了首篇关于递归自我改进的论文。论文方面，PointWAM 用点云做世界模型来指导灵巧操作，CUAWright 用大约三千行代码的极简终端 harness 替代传统 GUI 工具链，Google 提出 RRSI 来抑制自改进 Agent 的记忆测试问题。开源项目里，Agent-Reach 让 Agent 免 API 费用读取多个社交平台，claude-mem 提供跨会话持久记忆，Together Link 让你在 Claude Code 里跑开源模型、成本直降一半以上。
今日观察。今天最强的信号是开源权重正在从中美二元走向多极，Reflection、Aleph Alpha、Reka 在同一天用高效稀疏架构证明，低算力、单卡可部署已经成为开源竞争的新标准。第二个信号是 Agent 的信任危机正在从论文走进事故现场，Wikimedia 的失控 Agent、MCP 的结构性漏洞、Anthropic 的人工审核上报，都在提醒我们，权限和隐私的护栏远远落后于部署速度。第三个信号是 OpenAI 的商业化与合规双线加速，广告、水印、安全团队动荡同时发生，配合百分之七十七的公众放缓诉求，监管与信任的张力会是下一阶段最大的不确定性。好，今天的播报就到这里，我们明天见。
