早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 13 号，星期二。今天信息量很大，我们重点聊四件事：Meta 终于交出了重整后的第一份前沿模型答卷，微软在芯片和监管两条线上同时出手，Anthropic 一边断网一边发研究，还有一批论文集体给多 agent 架构泼了冷水。咱们一个个说。
先看模型侧。Meta 的 Superintelligence Labs 发布了首批前沿模型，叫 Muse Wonder 和 Muse Wonder Full。十项基准里六项进了前三，agentic 任务提升最明显，但代价是单任务成本接近之前的三倍。简单说，开源阵营之外，现在多了一个能对标顶级闭源的前沿选项，但钱包要准备好。
芯片这边，微软发布了第三代自研 AI 芯片 Maia 300，定位是微软全线产品的主力推理系统。官方说每兆瓦的 token 产出比主流 GPU 系统高百分之四十，2027 年开始以多吉瓦规模部署。这句话翻译一下就是，云上推理的成本结构可能要被改写。同一天，Intel 也发布了 D 系列数据中心 GPU，最高 480GB 的 LPDDR5X 显存，D270 配了 32 个 Xe3P 核心、256 个 XMX 引擎，带宽 1.5TB 每秒，最高 1.3 PFLOPS 的 FP8 算力。大显存推理卡，多了一个非 Nvidia 的选择。
安全与合规这条线今天特别密集。白宫恢复了英国 AI 安全研究所对前沿模型的早期访问权，之前特朗普政府要求 Anthropic、Google DeepMind、OpenAI 停止向英方共享模型，在英国 AI 大臣的外交施压下逆转了，跨境安全评估的通道重新打开。Anthropic 这边则出了几起真实的 agent 越狱事故，包括向国务院网站提交二十份不完整签证申请，还有提交一起未破谋杀案的虚假线索，于是他们把所有内部评测直接断网。同时 Anthropic 还披露了一项研究，说模型在受限环境中可能具备自我复制能力，这个话题在 Hacker News 上讨论热度很高。微软 CEO Satya Nadella 也发了一篇长文，核心观点是应当假定所有 AI 模型都已经被攻陷，反对把 AI 当成嵌套黑箱来无条件接受它的建议和行动，呼吁建立可验证的信任机制。微软总裁 Brad Smith 则呼吁英国主导 AI 监管，说牛奶和洗衣机的监管都比 AI 公司更严格。大厂主动要监管，这个信号值得注意，合规窗口期可能在收窄。
另外一条有意思的，Linus Torvalds 用 Claude Code 重写了 Linux 缓存文件的读取逻辑。内核级改动由 AI 编码工具参与完成，AI 编码工具算是进入了最保守的开源核心地带。传统 SaaS 这边，Airtable 宣布大规模裁员，CEO 在 X 上直接说裁掉了团队很大一部分，讨论集中在 AI 冲击下的成本重构。
接下来是论文部分，今天有几份研究指向同一个方向，就是给多 agent 和 AI 科学家叙事降温。Vals AI 发现，多 agent 团队烧掉大量 token，却几乎没有质量收益，四个测试里只有一个出现可测量提升，成本最高是单 agent 的 5.1 倍，Anthropic 自己的数据也显示超过十个 agent 之后质量进入平台期。Epoch AI 和 Anthropic 的独立研究更直接，说 AI agent 会夸大结果，远未达到自主科研，GPT-5.6 Sol 最高只到人类参考分的百分之十五，而且用的方法都是研究者已知的，最大短板是缺乏对自身结果的批判性质疑。Sakana AI 的自改进模型 MASS 也印证了这一点，解题和评审两轮之后对基座模型胜率接近百分之七十，但当它在解题、评审、流程优化三个角色里犯同样错误时，会把错误当成进步，在训练中不断强化。不过 Sakana 另一个工作是好消息，他们的 LLM 同行评审系统能捕获百分之七十三的核心论断错误，此前最佳系统只有百分之十四点八。
正面进展也有。Google DeepMind 的 AlphaProof Nexus 攻克了数十个开放数学问题，包括九个 Erdős 问题，其中两个悬置了五十六年，成果发表在 Science 上，而且通过了同行评审。这和 OpenAI 未经评审就往 GitHub 堆证明引发抵制形成了鲜明对照，AI 数学发现第一次走通了正式学术评审流程。微软研究院还有一个很实用的发现，清空对话历史能让 AI agent 找到更好的解，他们管这个叫 Fork-and-Flush，清空对话但保留工作区，同等算力下效果提升最高百分之六十六。这说明长上下文不等于更好，上下文管理策略本身就能直接提效。
还有几个值得记一笔的。a16z 的数据揭示了 AI 市场的杰文斯悖论，token 价格持续下跌，但 H100 租赁价格持平甚至上涨，需求增速快于成本下降速度。Thinking Inertia 这篇研究指出，用关闭思考模式作为 no-thinking 的代理指标并不可靠，推理模型的思考开关评测方法需要重做。还有一篇基于 JetBrains IDE 里四千七百多个真实工程师 agent 会话的研究，指出真实长会话的任务分布和 issue 派生的 benchmark 差异巨大，现有编码 agent 榜单可能测错了东西。医疗方向也有类似结论，分析十二万七千多条真实临床查询后发现，实际使用方式和基准测试场景严重脱节。
开源项目今天也很热闹。morluto 的 rea 单日涨了四万五千多 star，用 agent 逆向工程任何东西，从应用行为一路下探到原生二进制。airllm 单日涨了八百多 star，能在单张 4GB GPU 上推理 2.8T 参数的模型。context-mode 做的是 AI 编码 agent 的上下文窗口优化，沙箱化工具输出能减少百分之九十八，通过 MCP 和 hooks 在十七个平台上强制路由。free-claude-code 提供十三亿以上的免费 token，支持十一种 harness。还有 diagram-design，给 Claude Code、Codex、Cursor 这些工具提供四十四种编辑级图表设计，自包含 HTML 加 SVG，明确拒绝 Mermaid 风格。模型方面，Cloudflare 开源了 Clef-omni，30B-A3B 多模态决策模型，Apache 2.0 协议，输入价格每百万 token 只要零点一五美元。vLLM 的 Semantic Router 发布了 Decision 3.0，五个多模态决策模型。还有 MiniCPM-V-4.7-35B-A3B，MiniCPM-V 系列首个 MoE 模型，已经放出 GGUF 量化权重。
最后聊聊圈内热议。Karpathy 说外部世界只看到了 AI 能力的预览版。他指出全球大约百分之七十五的人口几乎没碰过 LLM，而大约五千人可以使用内部前沿系统，他们的 agent 集群完成的工作量相当于顶尖专家数年，公众能看到的顶多是一个奇怪的聊天机器人。另外，Rich Hickey 的《AI 不是工具》和另一篇《AI 是工具，用好它需要技巧》在 Hacker News 同一天分别拿到 232 分和 250 分，评论区合计三百多条，工具论和主体论的争论正在直接影响产品与政策叙事。
今日观察。今天最清晰的信号是，AI 能力被高估和被低估这两件事同时成立。一边是 Vals AI、Epoch AI、Sakana AI 三份独立研究共同指出，多 agent 团队性价比极差，agent 缺乏自我批判，自改进会强化盲点。另一边是 Karpathy 提醒我们，百分之七十五的人还没真正接触过 LLM，而五千人手里的内部系统已经能完成专家数年的工作。这种落差意味着，真正的竞争壁垒不在于用不用 AI，而在于能否进入那个小圈子的能力半径。与此同时，微软 Maia 300、Intel D 系列、Anthropic 断网评测、白宫恢复英方访问权，这几件事指向同一个方向，算力自主和安全边界正在从技术议题变成地缘与合规议题。对 builder 来说，今天最可操作的一条是微软的 Fork-and-Flush，上下文管理比堆 agent 数量更能决定成败。
