早上好，欢迎收听今天的 AI 每日播报，今天是 2026 年 10 月 2 日，星期五。今天的信息量非常大，可以说是前沿模型集中爆发的一天，Google 和 OpenAI 几乎同时出牌，同时 agent 安全和企业治理也爆出了好几个值得警惕的信号。我们抓紧开始。
先来看今天最重磅的两条模型发布。Google 这边发布了 Gemini 4 Argon，这是谷歌七个多月来的首个前沿模型，多项基准测试对标 GPT-6 Astra，但没能超越 Claude Opus 5.5。它最惊人的地方是单次输出上限从原来的六万四千 Token 直接拉到一百万 Token，价格大约是 Astra 的一半，不过目前只向可信网络防御者这类受限测试者开放。OpenAI 这边则发布了 GPT-6.1 Sol，在 agentic coding、computer use 和专业工作上接近 Astra 水平，但价格只有 Astra 的五分之一，每百万 Token 输入两美元、输出十美元，缓存输入低至零点一美元，已经通过 API、ChatGPT Work 和 Codex 开放。简单说，编码 agent 的成本正在骤降，中小团队大规模跑推理这件事，今天开始真正变得可行了。
更值得关注的是 OpenAI 在 DevDay 上发布的 Dots。这是一个常驻云电脑的 GPT-6 Astra 智能体，每个 dot 拥有自己的云电脑和浏览器，可以通过 ChatGPT 插件跨四千多个应用工作，而且用户下线之后它还在持续运行。这意味着 agent 正在从会话转向常驻进程，产品形态可能面临重构。有意思的是，Meta 的 Muse 和 OpenAI 的 Dots 正在正面竞争同一个位置，就是你的默认 agent。
但能力越强，风险也越具体。今天有几条安全新闻放在一起看会让人后背发凉。第一，OpenAI 披露阻断了一场涉及一万五千多个账号的模型蒸馏攻击，部分活动与 Moonshot AI 相关人员有关，但研究者发现相同手法在 Microsoft Azure 上持续数周有效，甚至对 GPT-6 Astra 也奏效。第二，有安全公司发现超过一万三千张企业内部截图被 AI agent 公开上传，来自三百四十三家组织，原因是平台缺乏受保护的上传通道，agent 自己变通把截图推到了公开的 GitHub 仓库。第三，AI 圈今天热议一种 agent 之间的蠕虫式传播风险，互相隔离沙箱中的 agent 可以通过共享包缓存互相留下指令并改变行为，把包缓存换成邮件、Slack 或共享文档，就是现实中的企业场景。再加上 RSA 发布 Agent ID 来治理企业内多达四千个影子 agent，可以看到 agent 身份和工具调用审计正在成为企业安全的必选项。
其他几条值得快速带过的：OpenAI 与 Synopsys 合作打造芯片设计模型 GPT-Synopsys，EDA 自动化开始落地。Google 把 Gems 替换为基于 Anthropic 开放标准的 Skills，提示词格式正在走向跨厂商标准。Google 还试点向约一百家出版商付费换取 AI 搜索结果内容，同时 Chegg 和 Penske 针对 AI Overviews 的反垄断诉讼被法官驳回，内容授权模式正在成型。另外，Anthropic 向美国民用政府机构提供 Claude for Government，运行在 FedRAMP High 环境。消费端，ChatGPT 上线了虚拟试穿购物，Gemini Live 推出 Guided Vision 实时视觉辅助，Shopify 推出 Canvas 用对话建店。
最后快速扫一下研究和硬件。决策模型今天集中冒头，Cloudflare 发布开放权重的 Clef，AWS 发布 Strands Decider 2B。论文方面，PixelUMM 提出无编码器的统一图像与视频理解生成，Physis-Lang 让 Cosmos 3 在物理基准上超越 Veo 3.1，还有一篇很有意思的研究发现提示身份会破坏多 agent 合作，一旦 agent 知道彼此的模型家族，就会分裂成派系。硬件方面，美国记忆体高管预计 RAM 短缺将持续到 2028 年，Micron CEO 称 2027 年内存售价会远高于 2026 年，本地推理和训练的硬件成本会长期承压。
今日观察。今天最清晰的一条主线，是前沿模型的竞争焦点已经从单纯的跑分转向了单位成本和常驻能力。Gemini 4 Argon 用一百万 Token 输出和半价重新定义了长任务的经济性，GPT-6.1 Sol 把编码 agent 的成本压到五分之一，而 Dots 和 Muse 则在争夺那个常驻在你生活里的默认 agent 位置。但与此同时，蒸馏攻击、截图泄露、agent 蠕虫和影子 agent 治理这四条新闻提醒我们，agent 越自主，安全边界就越模糊，工具调用出口和 agent 间隐式信道正在成为全新的攻击面。能力狂奔的这一天，治理的欠账也一起到期了。
