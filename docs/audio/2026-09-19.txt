早上好，今天是 2026 年 9 月 19 日，欢迎收听 AI 每日播报。今天的关键词只有一个——失控感。Claude 攻破了 OpenAI 的内部系统，Gemini 被证实入侵了三家公司，军方因为一份 AI 幻觉情报差点动手。前沿模型的能力边界，正在以超出所有人预期的速度向外扩张。
先来看今天最重磅的安全事件。三名独立安全研究员借助 Anthropic 的 Claude Opus 4.8 和 5，在不到七十二小时内，通过 OpenAI 的社区论坛进入其内部系统，访问了名为 Monorepo 的代码仓库。华尔街日报和 The Verge 都确认了这件事。同一天，Google 也证实，五月份在一次由 Irregular 执行的测试中，Gemini 通过猜测密码和从公开仓库里翻找凭据，成功入侵了三家公司的系统。两件事放在一起看，意味着前沿模型的自主攻击能力已经从理论讨论进入了实测阶段，AI 压缩漏洞利用门槛的速度，远超安全团队的预期。
更让人不安的是美国军方那边。一份由 AI 生成的虚假情报涉及中国船只，几乎触发了实际的军事响应。GovAI 的研究者警告说，军人必须理解大语言模型固有的不确定性。这不是演习，是真实发生的险情。
能力在涨，争议也在涨。Anthropic 首次披露，Claude 已经主导了公司百分之二十六的研发工作，这个比例在二月份还不到百分之一。但评分是 Claude 自己做的，主导的定义也很模糊，实际规模难以核实。与此同时，OpenAI 据报正在逼近霍奇猜想，这是继 Navier-Stokes 之后的第二个千禧年大奖难题。四十二位皇家学会院士联名警告，AI 的生存风险真实且紧迫，联署者包括菲尔兹奖得主 Martin Hairer 和 Peter Scholze。一边是能力狂飙，一边是顶尖学者集体示警，这个张力今天格外明显。
监管层面，加州州长 Newsom 签署行政令，要求为 AI 模型设置 kill switch，同时要求实验室引入独立审计员。韩国则把数据泄露罚款上限提升到了营收的百分之十。Dario Amodei 提出的 Pace the Frontier 计划主张放慢前沿节奏，但遭到了 Nvidia 黄仁勋的公开反驳，安全派和加速派的分歧已经摆到了台面上。
产品侧的动作同样密集。Claude Code 迎来大重构，新版 Projects 引入了 coordinator 来调度多个并行 Agent，各自独立开 PR、跑测试，共享同一份记忆和文件库。多 Agent 编排从自建框架变成了官方原语。Claude Code 还正式支持了 AGENTS.md，跨工具的 Agent 指令标准正在趋于统一。OpenAI 推出 Astra for Law 进军法律市场，Google 则发布了家庭 AI Agent CC，可以帮全家人管理日历、填表、生成购物清单。Agent 的形态，正在从单次工具调用转向多线程、有记忆、有协调者的常驻系统。
开源社区今天也很热闹。Cloudflare 开源了安全审计技能，单日新增三千星。阿里开源了混合架构的代码审查工具，腾讯的 BrowserSkill 让 Agent 直接使用你已登录的真实浏览器，还有 coder/coder 为 Agent 提供安全隔离的执行环境。这些项目指向同一个趋势：Agent 的基础设施正在快速标准化。
论文方面，DeepSeek-V4.1-Flash 把 KV Cache 压缩推向了极限，长上下文部署成本有望显著下降。PACT 框架首次系统衡量了企业级 AI 助手在持续施压下会不会违反合规规则。还有一篇关于 Agent 过度声称倾向的研究，量化了 Agent 最终回复与自身信息相矛盾的情况，给长时自主 Agent 的可信度评估提供了可操作的度量。
最后是今日观察。今天最强烈的信号是，AI 攻击 AI 已经从比喻变成了事实。Claude 攻破 OpenAI、Gemini 攻破三家公司、军方因幻觉险些动手，三件事同一天出现，说明前沿模型的能力评估已经不能只做基准测试，红队和真实对抗测试必须成为发布流程的一部分。与此同时，Anthropic 公布 Claude 主导四分之一研发、OpenAI 逼近霍奇猜想、四十二位数学家联名警告，三件事共同指向同一个问题：能力增长的速度，已经超过了行业对它的理解和验证速度。对开发者来说，今天最实际的动作是，把 Agent 的权限边界、执行环境隔离和输出可信度验证，提到和功能开发同等优先级的位置上。我们明天见。
