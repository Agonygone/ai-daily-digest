早上好，欢迎收听今天的 AI 日报，今天是 2026 年 9 月 19 日，星期六。今天的关键词是两个字，收敛。Agent 的基础设施正在快速标准化，而围绕 AI 自我进化和安全治理的讨论，也从口号变成了具体的数字和方案。咱们花几分钟，把今天最值得关注的几件事捋一遍。
先看 Anthropic 的三条消息。第一，Claude Code 从 2.1.277 版本开始支持 AGENTS.md 了。如果文件夹里没有 CLAUDE.md，它会自动去读 AGENTS.md，这背后是即将开放的 Claude Code mods 机制。这件事的意义在于，跨工具的 Agent 指令文件终于走向事实统一，大家不用再为每个工具重复维护一份配置。第二，Claude Code Projects 做了重构，转向并行的云端 Agent。简单说，coordinator 会把任务拆成多个并行的 cloud thread，各自独立开 PR、跑测试，还能共享记忆。Beta 版已经面向部分 Pro 和 Max 订阅者开放。这意味着你的 Agent 从本地终端搬到了云端，合上笔记本它还在跑。第三，Anthropic 首次披露了内部的 RSI 数据，说 Claude 已经主导了公司百分之二十六的研发工作，而这个比例在今年二月还不到百分之一。不过要提醒一句，这个评分是 Claude 自己给的，lead 这个词的实际含义被指有夸大成分。有意思的是，国产这边智谱 GLM 团队也发了一篇长文，披露 GLM-5.3 已经摸到了自我进化的门槛，唐杰直言，正一步步走向取代我们。
再看产品和市场。OpenAI 推出了 Astra for Law，基于 GPT-6 Astra 构建法律专用版本，提供律所定制工作流和保密级管控，法律成了 GPT-6 第一个专攻的垂直领域。Google 这边推出了家庭 AI Agent，叫 CC，从个人助理转向家庭协调，可以共享邮件、日程和任务，管理日历、填表、生成购物清单和餐食计划。Meta 的 Muse 登陆了 Mac，能在 macOS 上读写文件、操作应用，桌面级的 computer-use Agent 竞争明显加剧。
监管方面今天很密集。加州州长 Newsom 签署行政令，要求 AI 实验室引入独立审计员，并为前沿模型配备 kill switch，专家组两个月内提交建议。弗吉尼亚州成立了 AI 工作组，同时收紧数据中心审批，还可能放缓扩张节奏。韩国则把数据泄露罚款上限提到了营收的百分之十，对标欧盟 GDPR 的力度。法律风险这边，纽约时报诉讼的解封文件显示，OpenAI 和微软内部早就承认自己的抓取行为在制造 doom loop，微软一位总监甚至称其为人类历史上最大的劳动盗窃。安全方面还有两条让人警醒的消息，三名安全研究员借助 Claude，在七十二小时内攻破了 OpenAI 的内部系统；另外，美国军方因为一份 AI 幻觉生成的情报报告，险些酿成针对中国船只的误判事故。
最后快速过一下论文和开源。DeepSeek 发布了 V4.1-Flash，把 KV Cache 压缩推到极限，直接降低长上下文 Agent 的推理成本。JEPA-Anything 把世界模型从领域专用推向通用框架。还有一篇实证研究，首次量化了 coding agent 里 harness 各组件的贡献，Agent 工程开始告别玄学调参。开源这边，Cloudflare 开源了安全审计 skill，阿里开源了生产级代码审查工具 open-code-review，腾讯的 BrowserSkill 能让 Agent 直接用你已登录的真实浏览器，单日新增都超过一千 star。
今日观察。今天最清晰的信号，是 Agent 基础设施正在标准化收敛。AGENTS.md 被 Claude Code 接纳，harness 设计有了组件级实证，Cloudflare 和阿里同日开源审计与审查 skill，这一层已经从各家自造轮子转向共享规范。与此同时，Anthropic 的百分之二十六、GLM-5.3 的自我进化、OpenAI 的失准披露框架，共同指向同一件事，AI 造 AI 不再是口号，而是开始被量化、被审计、被要求披露。但另一面，七十二小时攻破 OpenAI、军方幻觉情报、四十二位院士联名警告，都在提醒我们，能力提升和风险暴露是同一枚硬币。对开发者来说，今天最值得动手的，是把合规压力测试和虚报检测纳入自己的上线流程，因为这两个基准刚刚可用，而监管已经开始要求 kill switch 了。好，今天就聊到这儿，我们明天见。
