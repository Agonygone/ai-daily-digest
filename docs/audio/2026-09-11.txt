早上好，今天是 2026 年 9 月 11 号，欢迎收听今天的 AI 日报。今天的关键词是 Agent 基础设施集体成熟，以及治理争议集中爆发。咱们分几个板块来聊。
先看 OpenAI，今天一口气放了好几个大招。最重磅的是 Agents API，一个托管式的云 Agent 服务，基于 Codex harness，提供编排、长时运行会话和工具调用能力。这意味着 Agent 从自己搭编排走向托管服务，生产化的门槛一下子低了不少。同时上线的还有 GPT-Live-1 语音 API，全双工语音模型，能同时听和说，交互性测试得分从上一代的百分之四十五点四直接拉到百分之八十点一，定价是每分钟五美分。实时语音 Agent 的体验可以说是质变了，但成本还是要精算。另外，OpenAI 还推出了面向金融行业的 ChatGPT for Financial Services，结合内置金融数据和 GPT-6 Astra，做研究、建模和客户材料生成。ChatGPT Work 也上线了 Data Agent，能连企业数据，用自然语言生成洞察和交互式仪表盘，BI 类的工作流直接被 Agent 接管了。不过有个消息值得注意，OpenAI 因为 Astra 的需求压力，暂停了 Pro 订阅的新注册，说是要扩容。前沿模型的算力瓶颈已经直接传导到销售端了。
再看 Anthropic，今天有两条。一是披露了中国厂商的蒸馏攻击报告，指控阿里、Moonshot AI 和 DeepSeek 持续开展蒸馏活动，而且近几个月还在升级。这个争议公开化之后，可能会影响合规和授权谈判。另一条是 Anthropic 说已经阻断了可能的生物武器构建尝试，生物安全正在成为前沿实验室红线级别的风控场景。
Meta 这边，发布了 AI Agent Muse，直接登上美区 App 榜第二。用户通过 WhatsApp 就能完成购物、写邮件、议价，支付走 Stripe Link，还有一个叫 Sentinel 的安全 Agent 监控每一次操作。这是 Agent 第一次大规模嵌入十亿级的社交入口。Slack 也不甘落后，推出了 Slackforce Surfaces，可以在聊天里用自然语言生成交互式报表、投票、仪表盘和微型站点，办公协作工具里直接 vibe-code 应用。
其他行业动态快速过一下。英伟达和 Palantir 合作，用 AI 运行供应链，第一个落地场景就是英伟达自己的百万级零部件运营。Ramp 的数据显示，头部 AI 支出企业的人均成本八月降了近百分之十，每百万 token 价格从三月以来下降了百分之四十一，企业正在主动从昂贵的前沿模型转向低价替代。音乐领域，环球音乐联手 ElevenLabs 推出 AI 音乐平台，用户基于授权曲库创作混音和改编。Suno 也发布了 v6 音乐模型，是首个获唱片业支持训练的版本。苹果这边，iPhone 18 Pro 推出了 Reference Image 防伪模式，新相机传感器给每个像素签名，证明照片没被 AI 篡改，这是硬件级的内容溯源。国内方面，DeepSeek 发布了 V4.1-Flash，五百五十二 B 基座，总参数约七百四十八 B 的多模态 MoE，每 token 只激活十六 B，KV Cache 降到前代的四分之一，MIT 许可，在 DeepSWE 编码基准上略胜 Opus 5 和 GPT-5.6 Sol。高德发布了全球首个 3D 原生城市世界模型 ABot-Earth 0.7，为具身智能和仿真提供底座。
论文方面，今天有几篇值得关注。PARSER 把长上下文 Agent 的阅读和推理解耦，轻量子 Agent 并行读全文，主 Agent 迭代深推，延迟和鲁棒性同时改善。SWE-Bench Pro Verified 修复了原版的奖励攻击和任务质量问题，重建了软件工程 Agent 评测的可信度。SchemeArena 对 LLM Agent 的阴谋行为做因子化压力测试，把对齐风险从轶事变成可复现评测。还有 Φ-Bench，评估 LLM 能不能工程化支撑自身的基础设施。StochBench 用 Lean 4 做随机过程定理证明基准。Show-Harness 让 VLM Agent 直接玩机器人，免训练、可跨本体。DF26 这个基准更值得警惕，二百七十一条真实加两千四百二十条合成演讲视频，人类和最先进的深伪检测器都表现不佳，现有方法基本失效。另外 AlphaGenome Atlas 发布了人类基因组全部单碱基变异的预测图谱，覆盖九十亿个变异。
开源项目今天也很热闹。i-have-adhd 一天涨了三千八百多 star，让编码 Agent 不再把答案埋在长篇输出里。diagram-design 提供三十八种编辑级图表类型，输出自包含 HTML 加 SVG。腾讯开源了 teamai-cli，清华的 OpenMAIC 做多智能体互动课堂。superpowers 是 Agent skill 框架和方法论。OmniRoute 是免费 MIT 的 AI 网关，单端点接入三百五十二家供应商、一千两百多个模型，还能配额感知自动降级。colibri 用纯 C 零依赖，从磁盘流式加载专家权重，在消费级硬件上跑前沿 MoE 模型。
最后聊聊今天的两大热议。一是 OpenAI 数学突破陷入数据来源争议。GPT-6 Astra 宣称解决 Navier-Stokes 千禧年问题之后，第二位数学家公开指控 OpenAI 使用了未发表工作且缺乏透明度。Terence Tao 也警告说，好问题正被 AI 以不可再生的方式开采，激励可能指向不再分享有价值的研究方向。另一条是 Anthropic 离职研究员 Jacob Coxon 在 CNN 发出末日警告，说自我改进 AI 构成生存威胁，Anthropic 内部存在迷你曼哈顿计划，实验室只剩几年时间让系统变安全。这个话题被政界和 Joe Rogan 放大，同时也有声音指出其中夹杂文化和商业利益。
今日观察。今天最清晰的信号是 Agent 基础设施的集体成熟。OpenAI 一次性放出 Agents API、GPT-Live-1 和 Data Agent，Meta 把 Muse 塞进 WhatsApp，Slack 让聊天窗口直接生成应用，Agent 不再是 demo，而是被当作产品骨架来交付。与此同时，DeepSeek V4.1-Flash 用四分之一的 KV Cache 和 MIT 许可把开源 Agent 的推理成本再压一档，配合企业人均 AI 支出下降近百分之十、token 单价半年跌百分之四十一，能力提升加价格下降的双击正在真实发生。另一条暗线是治理与信任，蒸馏指控、数学数据争议、末日警告同一天占据头条，前沿实验室和学术界、监管方的关系正在重新定价。对开发者来说，现在最值得投入的不是再训一个模型，而是把 harness、路由和评测这三层做扎实。今天开源的 OmniRoute、superpowers 和 SWE-Bench Pro Verified 恰好各占一角。好，今天的日报就到这里，我们明天见。
