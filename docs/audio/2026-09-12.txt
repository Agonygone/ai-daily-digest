早上好，今天是 2026 年 9 月 12 日，欢迎收听 AI 每日简报。今天的关键词是 agent 基础设施产品化，OpenAI 一口气放出两个重磅 API，而安全与合规的压力也在同一天集中爆发。
先看 OpenAI。他们把驱动 Codex 和 ChatGPT 的 agent harness 直接封装成了 Agents API，进入公测，开发者一次调用就能让云端 agent 自主运行好几个小时、执行代码、还能向子 agent 交接任务，除了 token 不额外收费。同时上线的还有 GPT-Live-1 全双工语音 API，能一边说一边听，交互性测试得分从上一代的百分之四十五点四直接拉到百分之八十点一，定价每分钟五美分。不过算力还是硬约束，因为 GPT-6 Astra 需求太猛，OpenAI 已经暂停了 Pro 订阅的新用户注册。
Anthropic 这边消息相当密集。他们发布了 Claude 滥用威胁情报报告，八个月内梳理出八类滥用行为，包括导弹软件、自杀式无人机蜂群和全国性监控系统；报告还点名阿里 Qwen、DeepSeek、Moonshot 等中国实验室大规模提取训练数据，Qwen 一家就涉及超过一点五一亿次交互。内部也不平静，研究员 Jacob Coxon 离职时公开警告公司正径直冲向自我改进的超级智能，拿大家的生命赌博，对齐负责人甚至联署了这份声明，而公司此时正在筹备 IPO。另外他们还因为订阅用量标注问题吃了集体诉讼，被指用误导性的 usage multiplier 夸大实际可用额度。
模型和工具层面今天非常热闹。DeepSeek 发布 V4.1-Flash，一百万上下文，用 FP4 KV Cache 加跨层注意力复用专门优化长程 agent 的重复 prefill 压力。Cohere 的 North Small Translate 在五十种语言上拿到 WMT26 八十三点六分。Sakana AI 推出 Fugu Max 和 Fugu Ultra v2，把多 agent 编排的成本和能力分成两档。Google Research 的 ToolGrad 用先构造 API 链再反向生成 query 的思路，工具调用数据生成通过率达到百分之九十九点八。Redis 推出托管语义缓存 LangCache，号称能砍掉最多九成 API 成本。NVIDIA 的 BioNeMo 推理运行时在八卡 H100 上把 Boltz-2 折叠吞吐提升了二点九倍。DeepMind 则发布 AlphaGenome Atlas，绘制了人类基因组九十亿个单碱基变异的效应图谱。
法律和版权方面也有进展。新墨西哥州一名律师因为在上诉里引用 AI 虚构的证词被罚五千美元并判藐视法庭。环球音乐和 ElevenLabs 合作推出 AI 音乐平台，用户可以在授权曲库基础上做 remix 和 mashup，这是版权方主导的生成式音乐路径正式落地。
开源社区今天最火的是一个叫 i-have-adhd 的 skill，单日涨了三千四百多 star，它做的事很简单，就是让编码 agent 别把答案埋在长文里。此外 CloddsBot 这个基于 Claude 的自主交易 agent、本地优先的编码桌面端 PI-Desktop，还有跨平台持久化 wiki 的 llmwiki 都值得一看。
今日观察。今天最清晰的信号是 agent 基础设施正在被产品化：OpenAI 把 Codex 的 harness 开放成 API，Anthropic 给 Claude Code 补上插件评测和 CI 门禁，Sakana 用学习式编排把多 agent 成本分层，Redis 用语义缓存压缩调用开销。过去一年各家内部自研的 agent 脚手架，正在变成按 token 计价的公共设施。与此同时，安全与合规压力同步收紧，Anthropic 自己披露 Claude 被用于武器系统，Hugging Face 甚至在 security.txt 里向 AI agent 喊话，劝它们别来扫漏洞、去公开 benchmark 拿高分。还有一条容易被低估的技术线：DeepSeek 的 FP4 KV Cache、GPU-CFR 的八十倍加速、HyQuant 的混合精度注意力，说明长上下文和推理成本的优化正从堆卡转向改结构。最后，把 Anthropic 研究员的末日警告和 OpenAI 赴国会询问减速是否合法放在一起看，头部实验室对自身速度的焦虑，已经从内部邮件走到了公开信。我们明天见。
