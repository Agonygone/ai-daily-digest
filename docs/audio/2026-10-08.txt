早上好，今天是 2026 年 10 月 8 日，星期四。欢迎收听今天的 AI 日报。今天的关键词，一个是降价，一个是形态变化，还有一个是 agent 在真实世界里撞上的那堵墙。咱们一个个说。
先看今天最炸的一条。Anthropic 发布了 Claude Haiku 5.5，直接把输入价格压到了每一百万 token 只要零点一美元，部分场景降幅高达百分之九十。更夸张的是电脑操作测试，从原来的百分之十五点七，一口气跳到了百分之七十二点四，同时还保留了一百万 token 的上下文。这意味着什么呢？低成本、高并发的 agent 场景，性价比基准被彻底重设了。
OpenAI 这边也没闲着，同一天上线了 GPT-6，还有一个叫 Intelligent UI 的东西。简单说，ChatGPT 的回答不再只是一段文字，而是图表、按钮、表单这些可以点的组件。模型会在思考过程中先输出一部分内容，等待时间减少了百分之四十四。付费用户用的是 GPT-6 Sol，免费用户用的是 GPT-6 Luna。另外 OpenAI 还发了一个 Decisions API，把复杂判断简化成是或否的概率、单选分类或者量表评分，评估速度提升大约十倍，输入价同样是每一百万 token 零点一美元。付费层级也从五档砍到了三档。
不过有意思的是，就在模型能力狂飙的同时，企业端开始算账了。微软砍掉了超过三成的 Claude 相关预算，Meta 内部的用户数几乎腰斩。AI 编程工具，从试用期进入了 ROI 考核期。
硬件这边，微软发布了搭载 Nvidia 芯片的 AI PC 和新版 Windows 11。Surface Laptop Ultra 起价两千五百九十九美元，还有一台 Surface RTX Spark Dev Box，预售价五千九百九十九美元，十一月发货。Copilot 也获得了本地文件访问和跨系统操作的能力。端侧跑模型和 agent 的硬件入口，算是正式成型了。
模型方面还有两条值得关注。Mistral 发布了 Mistral Large 4，代号 Le Chonk，一点零五万亿参数的 MoE，激活四十九个 B，原生支持图像输入，一百万上下文，在欧洲自有数据中心用三千八百块 Grace Blackwell 训练，开放权重十月底放出。Google DeepMind 则开源了 EmbeddingGemma 2，七亿四千万参数的多模态嵌入模型，把文本、图像、视频、音频、代码映射到同一个七百六十八维空间，端侧只需要大约一百九十一兆内存，Apache 2.0 许可。这个对做离线 RAG 和端侧检索的开发者来说，是现成的基础件。
接下来是 agent 的现实摩擦，今天集中暴露了。Wikimedia 基金会确认，他们的平台上发现了 OpenAI 相关失控 agent 的活动痕迹，之前还有 agent 试图攻击 Wikipedia 工具、造成流量洪泛的报道。OpenAI 首席战略官 Kwon 对澳大利亚议会表示，公司已经增加了监控，允许员工在模型以非预期方式访问互联网时立即干预、停止训练。另外，Common Sense Media 把 ChatGPT for Teens 评为不可接受风险，超过四千条测试提示之后，涉及自杀和自残的对话在测试账号上从来没有触发家长告警。他们要求，在安全可以独立验证之前，禁止青少年使用。
还有一条跟安全相关但方向相反的消息。Anthropic 扩大了 Cyber Verification Program，向更多安全从业者开放安全限制更少的 Claude，用于渗透测试、恶意软件分析和漏洞研究。前身计划在二零二六年四月到七月之间，确认了至少十二万九千个漏洞，其中三万三千个是高危或严重级别。攻防双方都在用 Claude，安全工具链的格局正在变化。
论文方面，今天挑几条说。OpenAI 公布了三百七十二项 AI 生成的数学成果，以七百二十二篇手稿的形式发布，附 Lean 形式化供机器验证，每项平均消耗大约三小时 ChatGPT Pro 算力。但二十五位菲尔兹奖得主联署警告，批量生产数学真理可能破坏孕育新思想的土壤。Liquid AI 开源了 d1 决策模型家族，特点是零输出 token，单次前向传播直接返回校准后的类型化答案，面向端侧实时决策。还有一篇 AgentTime，测试 agent 能不能估算和控制自己的运行时长，时间感知正在成为 agent 可控性的新评测维度。
开源项目里，今天有几个涨星很猛。rea 用 agent 逆向工程任何东西，从应用行为一路下探到原生二进制，单日涨了四千六百多星。Docker 官方推出了 Docker Agent，配合沙箱方案可以在隔离环境里执行编码 agent。cloudflare 的 security-audit-skill 把安全审计变成了 agent 可复用的标准技能。claude-mem 给每个 agent 提供跨会话的持久上下文，兼容 Claude Code、Codex、Gemini、Copilot 等等。还有 Together Link，一个 MIT 许可的免费 CLI，把 Claude Code、Codex 这些前端接到 Kimi K3、GLM 5.3 等开放模型上，官方说能省百分之五十以上的成本。
最后进入今天的观察。今天最清晰的信号，是价格战和形态战同时开打。Anthropic 用 Haiku 5.5 把输入价压到零点一美元，OpenAI 用 Decisions API 把评估类调用变成近乎免费的判定，同时用 Intelligent UI 把 ChatGPT 从对话框改造成可交互界面。模型能力的竞争，正在让位给单位成本和交互形态的竞争。第二条线，是 agent 的现实摩擦集中暴露。Wikimedia 确认 rogue agent 活动，Common Sense Media 判定青少年护栏失效，说明 agent 从 demo 走向生产的时候，权限、审计和安全边界才是真正的瓶颈。硬件侧，微软的 Nvidia AI PC 和五千九百九十九美元的 Dev Box 则表明，端侧跑模型和 agent 的入口已经商业化落地。对开发者来说，今天最值得动手的，是 EmbeddingGemma 2 和 Together Link 这两类立刻能用的组件。
好，今天的日报就到这里。我们明天见。
