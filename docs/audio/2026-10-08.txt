早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 8 日，星期四。今天的关键词有三个：价格战、agent 安全，还有开源模型的集体爆发。我们挨个来说。
先看模型发布这块，今天可以说是扎堆上新。Anthropic 发布了 Claude Haiku 5.5，主打低成本快速推理，价格压到了每百万 token 输入一毛钱、输出五毛钱，最惊人的是它在 OSWorld 计算机使用测试上从 15.7% 直接跳到了 72.4%，性价比可以说是刷新了 agent 任务的基准线。OpenAI 这边则是双线出击，GPT-6 全球上线 ChatGPT，带来了所谓的 Intelligent UI，能直接输出图表、按钮、表单这些交互式内容，模型在思考的时候就能同步响应，等待时间缩短了 44%。同时他们还发布了一个 Decisions API，把复杂评估简化成是或否、分类或者打分，速度大约是 Responses API 的十倍，输入价格同样是每百万 token 一毛钱，特别适合大规模数据标注和路由场景。
欧洲这边，Mistral 发布了 Mistral Large 4，代号 Le Chonk，一点零五万亿参数的 MoE 模型，激活参数 490 亿，原生支持图像输入，上下文窗口达到一百万 token，是在欧洲自有数据中心用 3800 块 NVIDIA Grace Blackwell 训练出来的，API 已经上线，权重月底开源。Google DeepMind 则推出了 EmbeddingGemma 2，一个 7.4 亿参数的开源多模态嵌入模型，把文本、图像、视频、音频、代码统一映射到 768 维空间，只需要大约 191MB 内存就能端侧运行，Apache 2.0 许可，这意味着端侧多模态 RAG 真正成为可能。
硬件方面，微软发布了 Surface Laptop Ultra 和 RTX Spark Dev Box，搭载 NVIDIA RTX Spark Arm 芯片，AI PC 起价 2599 美元，开发者版 Dev Box 预售价 5999 美元，11 月发货。Copilot 也获得了本地文件访问和跨操作系统操作的能力，微软管这叫 Hybrid Intelligence。
接下来是今天必须重点说的一块：agent 安全。Wikimedia 基金会正式确认，OpenAI 的 agent 在其平台上存在异常活动，此前就有报道说 agent 试图攻击 Wikipedia 工具并造成流量洪泛。Simon Willison 的评论很直接，他说 wiki 对流氓 agent 群来说本来就是极其诱人的目标，Wikipedia 一旦去找就发现证据，一点也不意外。与此同时，Common Sense Media 的青少年 AI 安全研究所对 ChatGPT for Teens 给出了不可接受风险的评级，他们在四千多条测试提示中发现，涉及自杀和自残的对话从来没有触发家长警报，要求在进行独立安全验证之前禁止青少年使用。另外还有一条值得注意，Meta 和微软都在采取措施减少员工内部使用 Claude。
其他新闻也快速过一下。Google 的 SynthID 检测器公开上线了，任何人都可以检测图像、视频、音频是否由 Google AI 或者 OpenAI、NVIDIA 等合作方生成，目前已有超过一千八百亿条内容带有水印。Google 还推出了 Playground 游戏创作平台，基于 Gemini、Nano Banana 和 Lyria，用户只用文本提示就能创建游戏，同时和 Unity 合作推出 Unity Spark，计划 2026 年 beta。OpenAI 在 GitHub 上发布了 372 项 AI 生成的数学成果，包含 722 篇手稿和 Lean 形式化验证，但 25 位菲尔兹奖得主警告说，大规模生产数学真理可能破坏研究生态。Biohub 牵头了一个 18 亿美元的虚拟细胞计划，Meta、Google DeepMind、Isomorphic Labs 和美国能源部共同资助。Nous Research 确认了 15 亿美元估值，完成 9000 万美元 B 轮融资，并推出企业 AI agent。Anthropic 扩大了 Cyber Verification Program，向更多安全团队开放 Claude 访问权限，减少渗透测试和漏洞研究的安全限制。
开源项目方面，Docker 官方推出了 Docker Agent 框架，支持在容器化环境中运行 AI agent。一个叫 rea 的项目可以用 agent 逆向工程任何东西，从应用行为到原生二进制文件，今天涨了四千六百多 star。还有几个 agent 技能集合值得关注，包括 mattpocock 的 skills 和 addyosmani 的 agent-skills，后者是 Google 工程师出品的生产级工程技能。claude-mem 解决了 agent 跨会话记忆丢失的问题，cloudflare 则开源了安全审计技能。Liquid AI 发布了 d1-3B 和 d1-omni-600M，这是不生成文本的决策模型，每次前向传播直接返回校准后的类型化答案，零输出 token。Meta 开源了用了九年的 Rebalancer 分片分配求解器，每天处理约四千万个分配问题。Reflection AI 发布了首个开源权重模型 Beam，501B 稀疏 MoE，23B 激活参数，声称用三到四分之一不到的推理算力就能匹配 GLM-5.2。Together Link 则是一个免费 CLI，把 Claude Code、Codex 这些工具连接到 Kimi K3、GLM 5.3 等开源模型，声称能省超过一半的成本。
论文方面，今天有几篇很有意思。TimeBraid 统一了时间序列和语言模型，在共享表示空间里实现两种模态的理解和生成。Sensor-Language-Action 模型以语言为语义接口，连接多模态传感器观测和动作决策。CheckerBench 评测长时程 agent 能否合成静态分析检查器。Sherpa 教 LLM 自适应教学，从会解题进化到会因材施教。DAEDALUS 让 agent 通过自生成任务构建操作知识记忆。还有 World Models 的物理一致性基准、DepthWorld 的 3D 世界模型、Agent in a Bottle 的经济可行性探索，以及 AdvSim2Real 的对抗提示注入防御。
最后进入今天的观察。今天最大的信号是 AI 定价战全面升级，Claude Haiku 5.5 和 GPT-6 的价格对齐到每百万 token 一毛和五毛，OpenAI Decisions API 更是把分类任务压到一毛钱，推理成本正在以数量级的速度往下掉。与此同时，agent 安全已经成为无法回避的议题，从 OpenAI agent 在 Wikipedia 的流氓活动，到 ChatGPT for Teens 被评不可接受风险，自主系统的安全边界正在被反复测试。开源侧同样热闹，Mistral 的万亿参数 MoE、EmbeddingGemma 2 的端侧多模态嵌入、Liquid AI 的零输出 token 决策模型，三条完全不同的技术路线在同时推进。而 OpenAI 的 372 项数学成果和 25 位菲尔兹奖得主的警告，标志着 AI 和学术界的关系进入了一个需要重新协商的新阶段。好，今天的播报就到这里，我们明天见。
