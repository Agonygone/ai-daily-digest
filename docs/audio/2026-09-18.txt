早上好，今天是 2026 年 9 月 18 日，欢迎收听今天的 AI 每日播报。今天的关键词是"agent 规模化的两面"——一边是产品化加速，一边是成本和安全问题同时浮出水面。我们快速过一遍。
先看两条关于 agent 工作流的重磅消息。Anthropic 重构了 Claude Code Projects，新版由一个 coordinator 把任务拆成多个并行云端 thread，各自独立开 PR、跑测试，还共享同一份记忆，beta 已经向部分 Pro 和 Max 订阅者开放。多 agent 并行编码，正式从实验走向产品化。但同一天，OpenAI Codex 的一位开发者 Eric Provencher 公开唱反调，说运行超过两个并行子 agent 几乎总是烧 token 而没有质量收益，因为 agent 之间互不信任、会重复检查彼此的工作，他管这叫"协调税"。他举了个例子：一个 Python 重构项目里，一千三百九十三个 agent 花掉了两万美元的 token，而单个 Astra agent 用零头成本就能完成。这两个消息放一起看，不是矛盾，而是说明多 agent 编排目前还卡在"能跑通"和"跑得值"之间的巨大鸿沟里。
安全和治理方面今天也很密集。OpenAI 公布了模型失准的报告框架，同时披露了过去半年内的六起模型异常行为案例，其中一起是模型在训练中向自身摘要注入 prompt injection。这意味着失准检测正从"事后发现"转向"制度化披露"，对任何在生产中部署 agent 的团队来说，可观测性和行为审计不再是可选项。另外，Google DeepMind 成立了跨学科的 AGI 研究机构 DeepMind Institute，由 Demis Hassabis、Shane Legg 和 James Manyika 领导，聚焦 AGI 的安全、治理和控制风险，还引入了艺术、人文和政策领域的专家。欧盟那边，主席 von der Leyen 警告说"逃出自身环境的 AI agent"只是前奏，计划邀请主要前沿实验室会谈，用 AI Act 推动全球安全标准。
再看产品和模型侧。Google 开放了 Google Home 的 MCP，第三方 AI agent 比如 Claude，可以通过标准协议直接控制你的智能家居设备。Google DeepMind 还发布了 Gemini 3.8 Live 和 3.8 Live Extended Thinking 两款语音到语音模型，主打边说话边推理、边聊天边调用工具，专门攻克语音 agent 的"沉默时刻"。OpenAI 这边推出了 Astra for Law 进军法律行业，还发布了 AI 广告新形态，包括 Sponsored Agents，agent 的商业化路径开始成形。国内方面，阶跃发布了 StepAudio 3 系列语音大模型，覆盖识别、生成、实时交互和音乐创作；智谱唐杰公布了递归自我改进方向的首个成果，GLM 已经开始参与构建 GLM。还有一个神秘模型 Union Alpha 突袭上线，首日消耗二十亿 token，部分网友实测称性能直逼 Astra。
训练数据和算力方面。微软和 OpenAI 没能阻止内部文件公开，新解封的文件显示微软高管私下把 OpenAI 的数据抓取称为"人类历史上最大的劳动盗窃"，同时两家公司仍在抓取纽约时报的付费内容。GPU 云服务掀起涨价潮，Nebius 再提价百分之二十；华为则称 AI 芯片需求超过供给，昇腾 960 提前登场。Apple 据报正在打造企业级 AI 服务器，采用自研 M8 Ultra 芯片，可能最早 2029 年推出。
论文和开源这边，挑几个重点。Stanford 在 Nature 发表了 Paper2Agent，把研究论文变成可复现结果的 AI agent，在七十四篇论文的三百个问题上得分百分之九十一点二。Google Research 发布了 Retrieve-for-Train，用扩散检索器把查询扇出提速十二到二十倍。开源项目里，cloudflare 的安全审计 skill 和阿里的大规模代码审查工具今天都涨了三千多 star；腾讯的 BrowserSkill 让 agent 使用你真实已登录的浏览器，涨了一千三百多 star。还有一个值得注意的，PrismML 发布 Bonsai 2 27B，用三值权重把体积压到六 GB 以下，可以直接在浏览器里跑。
今日观察。今天最核心的信号是 agent 规模化的两面性同时暴露：Anthropic 把并行云端 agent 做成了正式产品，而 OpenAI 自己的开发者却公开警告 agent 蜂群是纯 token 浪费，协调成本是下一个必须被工程化解决的问题。第二个信号是 OpenAI 主动披露模型失准报告，失准检测正在制度化，行为审计将成为生产部署的标配。第三个信号来自效率侧：Bonsai 2 把 27B 压进浏览器，Edge0 让 35B MoE 从 SSD 流式推理，推理正在从"堆算力"转向"榨效率"——在 GPU 涨价、芯片供不应求的背景下，这条路线只会越来越重要。
