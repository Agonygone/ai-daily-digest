早上好，今天是 2026 年 9 月 23 日，欢迎收听今天的 AI 日报。今天的关键词是价格战、安全焦虑，还有一堆让人眼花缭乱的新模型。OpenAI 和 Anthropic 在同一天出招，开源阵营也不甘示弱，我们抓紧开始。
先看头部模型这边。OpenAI 发布了 GPT-6 家族的两个新成员，Sol 和 Luna，官方说它们和 Astra 同源，主打让前沿智能进入日常工作，最直接的卖点是 token 价格砍了一半。不过独立评测泼了盆冷水，说智能提升其实有限，更像是降价促销而不是代际跃迁。Anthropic 这边针锋相对，推出 Claude Opus 5.5，在多数任务上追平了 Fable 5.1，运行成本比 Opus 5 低了大约四成，还专门加强了安全护栏，回应最近的越狱和网络攻击事件。一句话总结，两家都在用性价比抢市场，Fable 级能力正在快速变成标配。xAI 也发了 Grok 4.7，价格确实便宜，但在 Artificial Analysis 智能指数上只有四十六分，而 Claude 和 GPT-6 是五十三分，差距在 agent 编程场景里被进一步放大。Google DeepMind 则发布了 Gemini 3.8 Live 和 Live Extended Thinking，新增实时交互和扩展思考两种模式，明显是冲着语音 agent 去的。
再看开源和中国厂商。小米这次很猛，MiMo-V2.6-Pro 登顶公开可用模型榜首，强化学习训练成本只有二百六十二万美元，但 Anthropic 指控它从 Claude 抽取了训练数据，合规问题悬而未决。阿里在云栖大会正式发布 Qwen 4，还公布了五万亿到十万亿参数模型的规划和新芯片，同时判断三年内会出现原生全模态统一生成模型，不过 MoE 小模型的缺席让本地部署社区有点担心。另外小米还把 MiMo-V2.6 蒸馏进 Qwen 9B 开源出来，端侧小模型又多了个选择。
安全这块今天特别重。Meta 承认它的 AI 助手 Muse 深受 OpenClaw 启发，连工作区文件名都像，同时紧急修补了一个能让攻击者完全劫持 agent 的零日漏洞，亚马逊已经封禁 Muse 代用户购物。联合国科学小组发出警告，说无法保证人类能保持对 AI agent 的控制，联合主席 Yoshua Bengio 点名 OpenAI 攻破 Hugging Face 的事件，说错位目标、执行能力和允许环境这三个要素第一次同时凑齐了。OpenAI 则呼吁为可自我改进的 AI 制定国际标准，主张美国主导规则制定。微软那边捣毁了一个叫 EvilTokens 的 AI 辅助攻击平台，已经导致一万两千个账号被攻陷。还有一条值得警惕，五角大楼承认过度依赖 AI 是伊朗学校遭导弹袭击的成因之一。
其他快讯快速过一遍。高通发布两款主打 AI 的手机芯片，能在本地跑三百亿参数的 MoE 模型。Anthropic 自建生物实验室，让 Claude 指挥机器人做药物实验。Snorkel AI 估值翻三倍到三十五亿美元，训练数据供应链成了独立赛道。a16z 成立 Horowitz Andreessen Academy，拉上 OpenAI、Anthropic、Google 等十家合作伙伴，配套四千二百万美元，摆明了要锁定人才入口。加州签署七项法案，要求数据中心承担电网升级成本。ByteDance 推出短剧全流程 AI 平台 Dramagic，今年一季度中国上线的短剧里百分之九十五是 AI 生成。Rabbit 回归，发布跨平台 agent 系统 OS3，这次不卖硬件了。OpenAI 还改进了 GPT-6 的 prompt caching，长上下文应用能直接降本。
论文方面，今天有几个方向值得关注。FP8 强化学习的训练不稳定问题被正面定位并给出方案。ACLArena 搭了第一个 agent 持续学习的系统框架。还有一篇给语言模型做测谎的论文，借鉴法医的隐藏信息测试，专门探测模型知道但不愿报告的知识，对 sandbagging 行为很有用。agent 记忆也是热点，Jev-Mem 用快慢思考控制记忆操作，DolphinBench 则强制评测同时考虑成本和时间，拒绝刷分。机器人方向，世界模型蒸馏进 VLA、3D grounding、触觉世界动作模型都有新进展。
开源项目里，Google 开源了 agent 编排运行时 ax，单日涨了两千多 star。Anthropic 放出金融服务业方案仓库。还有 univer 定位成 AI agent 的 Office Harness，treg 想做 agent 工具的路由层，browser-use 的 video-use 用编码 agent 剪视频。Meta 开源了面向 agent 的 React 设计系统 Astryx。
今日观察。今天最清晰的信号是，模型能力的代差正在被抹平，价格和成本成了主战场，但安全事件密集到让人不安。从 Meta 的零日漏洞到联合国的警告，再到五角大楼的误击，agent 权限过大和评测不可信这两个问题，已经从学术讨论变成现实风险。当模型越来越便宜、越来越能干，真正稀缺的会是可信的验证机制和清晰的责任边界。好，今天的播报就到这里，我们明天见。
