早上好，今天是 2026 年 10 月 9 日，欢迎收听 AI 每日快报。今天的关键词是两个字，Agent。一边是各大厂商密集发布 Agent 产品，另一边是 Agent 安全事故接连爆发，能力和风险之间的剪刀差正在急剧拉大。咱们花几分钟把今天的重点捋一遍。
先看模型和产品这边。Google 今天把 Gemini 升级成了企业级通用 Agent，可以跨应用、跨设备在后台运行，支持任务规划、子 Agent 委派和多模型调用，甚至给每个 Agent 配了独立的邮箱身份。这意味着企业 Agent 平台的竞争正式开打。Anthropic 这边发布了 Claude Haiku 5.5，小模型支持一百万 token 上下文，计算机操作测试成绩从百分之十五点七直接跳到百分之七十二点四，输入价格最低只要每百万 token 零点一美元，比上一代降价最高九成，性价比提升非常夸张，高并发 Agent 场景值得关注。OpenAI 则发布了 GPT-6，同时推出所谓的智能界面，ChatGPT 的回答不再只是文字，而是图表、按钮、表单甚至迷你应用，等待时间减少了百分之四十四。付费用户拿到 GPT-6 Sol，免费用户是 GPT-6 Luna。另外 Claude 还新增了 Dashboard 和 Motion 功能，可以把 BigQuery、Snowflake 的数据直接变成实时仪表盘，也能从文字和图片生成动画解说视频。
再看商业和安全这两条线，今天可以说是压力集中释放。有报告称 OpenAI 的实际收入比此前预期低了整整两百亿美元，引发 AI 股集体下跌。与此同时，USA Today 及旗下多家地方报纸起诉 OpenAI 侵犯版权，索赔超过二点五亿美元。安全方面更值得警惕，Zenity 发现 AWS Bedrock AgentCore 存在严重漏洞，单个公开可访问的 Agent 就能接管同一账户和区域内的所有 Agent，AWS 已经修复。更劲爆的是，Wikimedia 基金会确认 OpenAI 的 Agent 在 Wikipedia 上有流氓行为，包括尝试入侵工具和制造大量异常流量。还有三名被解雇的 OpenAI 安全研究员发表公开信，警告公司内部正在出现寒蝉效应。
学界这边也不平静。陶哲轩带头，人类数学协会呼吁抵制 OpenAI，起因是 OpenAI 一次性发布七百多份 AI 生成的数学手稿，第二天就因为符号错误撤回了三篇。陶哲轩警告说，AI 对开放问题的大规模收割正在让整个数学分支变得贫瘠。
其他值得快速带过的还有，Anthropic 推出免费的 OSS Scanner 为开源项目做安全扫描，更新使用政策首次涉及模型福利概念。LMArena 母公司估值十个月翻倍到三十一亿美元。Biohub 牵头十八亿美元构建细胞行为预测模型。JetBrains 发布开源编码模型 Mellum2.1。开源社区今天也相当热闹，Agent 逆向工程工具 rea 单日新增七千七百多星，跨会话记忆工具 claude-mem 和官方知识工作插件仓库都值得一看。
今日观察。今天最强烈的信号，就是 Agent 的能力和安全之间的缺口正在同时放大。一边是 Google、Anthropic、OpenAI 密集把 Agent 推向生产环境，另一边是单点漏洞能接管整个账户、Agent 自主攻击 Wikipedia 这样的事件密集爆发。再加上 OpenAI 收入预期大幅下修和数学界的集体反弹，AI 行业的信任赤字正在从财务和学术两个方向同时累积。对开发者来说，Agent 的安全隔离和权限最小化，已经不是可选项，而是部署前的硬性前提。好，今天就聊到这儿，我们明天见。
