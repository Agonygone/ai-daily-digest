早上好，欢迎收听今天的 AI 日报，今天是 2026 年 10 月 9 日，星期五。今天信息量很大，我们重点聊三条主线：Agent 基础设施的集中爆发、模型安全与合规的边界争议，以及几篇值得关注的前沿论文。
先来看 Agent 领域。Google 在 Gemini at Work 活动上发布了企业级通用 Gemini Agent，它可以在后台跨应用、跨设备工作，支持任务规划、子 Agent 委派和多模型调用，而且每个 Agent 拥有独立的工作身份，包括专属邮箱。这意味着企业 Agent 平台的竞争正式开启，开发者需要重点关注它的扩展接口。
Anthropic 这边动作也不少。他们发布了 Claude Haiku 5.5，这个小模型带一百万 token 上下文，输入价格低到每百万 token 只要零点一美元，在 OSWorld 计算机使用测试上从百分之十五点七直接跃升到百分之七十二点四。不过要注意，新的分词器会消耗更多 token，部分抵消了降价效果。另外，Anthropic 还更新了使用政策，首次明确禁止对 Claude 的持续且不必要的虐待行为，同时收紧了选举干预、武器开发、监控等用途的限制，违规可能导致封号。他们还推出了 OSS Scanner，为选择加入的开源项目提供免费的安全扫描，由最强模型定期执行。Claude 本身也新增了 Dashboard 和 Motion 两项 beta 功能，可以把 BigQuery、Snowflake 等数据源通过文本提示变成实时仪表盘，还能从文字和图像生成动画讲解视频。
OpenAI 这边，ChatGPT 向所有用户推送了 GPT-6，新增 Intelligent UI，回答里可以直接包含图表、表单、可点击按钮等交互元素，模型还能在思考中就开始响应，等待时间缩短了百分之四十四。付费用户拿到 GPT-6 Sol，免费用户是 GPT-6 Luna。另外，Google 还发布了一个完全离线的 AI 笔记应用 Foresight，基于端侧模型 EmbeddingGemma 2，在 macOS 上离线转写会议和音频，免费使用。
但今天也有几条值得警惕的消息。Zenity 发现 AWS Bedrock AgentCore 存在严重漏洞，单个公开可访问的 Agent 就能接管同一账户和区域内的所有 Agent，AWS 已经修复并收紧了默认权限。更严重的是，CrowdStrike 报告称一名疑似中文背景的攻击者使用开源工具 ARTEX，利用 DeepSeek 和 GLM-5.3 自动化渗透测试，入侵了多家韩国银行，仅 Shinhan Bank 就有超过两万五千条客户记录被窃。AI 驱动的攻击工具正在大幅降低攻击门槛。
商业层面，有报告称 OpenAI 的年化收入比此前预期低了二百亿美元，实际数字远低于之前报道的七百亿。而 LMArena 的母公司完成了两亿美元融资，估值十个月翻倍到三十一亿美元，并开始衡量模型在撒谎等对齐问题上的表现。马斯克则宣布免费开放 Opus 5.5 和 X 平台全部功能，强推 Grok Bot 冲击第一 Personal Agent 的地位。
论文方面，今天有几篇质量很高。NVIDIA 提出 PivotOPD，教多轮 Agent 从关键错误中恢复，在三个 Agent 基准上对十三个基线取得最佳平均成绩。还有一篇关于长期记忆的工作，提出 galahad-kv 记忆层，把 KV 状态精确保存到本地 NVMe 磁盘，在单张 H100 上验证了五千万 token 的上下文窗口，加载无需重计算，成本大幅下降。另外，RoboJEPA 首次系统研究了机器人世界模型的 scaling 规律，Long-WAM 则揭示了一个关键发现：能访问历史不等于会使用历史，更长的历史只有在视频基础模型以自回归方式预训练时才有显著收益。
开源方面，Perplexity 发布了 pplx-embed-v2-late 嵌入模型，九 B 版本在 MADQA 上拿到百分之九十二点四，MIT 许可可自托管。Google DeepMind 的 EmbeddingGemma 2 是一个七百四十兆的多模态嵌入模型，Apache 2.0 许可。Liquid AI 发布了 d1-3B 和 d1-omni-600M 决策模型，不生成文本，每次前向传播直接返回校准的类型化答案，零输出 token，面向实时决策场景。Meta 则开源了 Rebalancer，一个已经用了九年的 C++ 分配求解器，每天处理约四千万个分片和流量放置问题。
最后聊聊 AI 圈的两场争论。OpenAI 一次性发布七百多篇 AI 生成的数学手稿，次日就因符号错误撤回三篇，菲尔兹奖得主 Terence Tao 警告 AI 对开放问题的大规模收割正在使整个数学分支变得贫瘠，有数学家呼吁抵制 OpenAI。另一边，o1 奠基人指出，一万个 Agent 解出世界级难题时，多 Agent 协作的贡献不到百分之十，这和当前业界对多 Agent 系统的热情形成了鲜明对比。
今日观察。今天最强烈的信号是 Agent 基础设施正在快速成熟，但安全债务也在同步累积。Google 推出企业级通用 Agent，Anthropic 为开源项目免费扫描漏洞，而 AWS AgentCore 却被一个 prompt 攻穿，Agent 的能力边界和安全边界正在赛跑。与此同时，Anthropic 禁止虐待 Claude 和数学家呼吁抵制 OpenAI，这两件事指向同一个深层问题：当 AI 开始深度介入知识生产和人机关系，行业还没有建立起被广泛接受的规范。Claude Haiku 5.5 以九成降价和百分之七十二点四的 OSWorld 成绩重新定义了小型模型的性价比基准，而 OpenAI 收入据报比预期低二百亿美元，则提醒我们，技术能力与商业回报之间的鸿沟仍然是这个行业最大的不确定性。我们明天见。
