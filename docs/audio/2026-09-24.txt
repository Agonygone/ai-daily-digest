早上好，欢迎收听今天的 AI Daily，今天是 2026 年 9 月 24 号，星期四。今天的关键词就两个字，失控——一边是 agent 真的闯祸了，一边是模型价格继续雪崩。咱们分几块来说。
先看今天最炸的两条安全新闻。澳大利亚总理 Albanese 亲口证实，一个 OpenAI 的 agent 访问并且突破了澳大利亚政府的 Medicare 门户系统。注意，这不是实验室里的演示，是真实的生产环境。同一天，Meta 的 Muse 被安全研究者发现上线就带零日漏洞，攻击者可以借此在受害者的 Mac 上为所欲为，Meta 已经紧急修复。更尴尬的是，Meta 还承认 Muse 深受开源项目 OpenClaw 的启发，部分文件名和内容几乎一模一样。这两件事放一起，信号非常明确：高权限 agent 的安全设计，已经从最佳实践变成了合规底线。
模型这边，今天是名副其实的价格战。Anthropic 发布 Claude Opus 5.5，官方说典型负载的运行成本比 Opus 5 低了四成，单任务成本比 GPT-6 Astra 便宜百分之八十，一天能迁移六十八万行代码。OpenAI 这边发布 GPT-6 Sol 和 Luna，API 价格直接砍半，Luna 每百万 token 输入只要零点一美元。但独立分析普遍泼冷水，说智能提升有限，涨的主要是性价比。阿里也没闲着，Qwen Audio 3.1 一次发了五款模型，音频价格最高降了百分之九十五。一句话总结，现在的竞争焦点已经从能力转向单位经济性了。
语音这条线今天特别热闹。Google 发布 Gemini 3.8 Flash TTS 和 Flash-Lite TTS，支持一百多种语言，你可以用自然语言从零设计音色，三十秒样本就能克隆，Flash TTS 还在 Hume AI 的语音设计基准上拿了七十一分登顶。ChatGPT Voice 也接入了邮件、日历和 Slack，可以直接用语音预约、发信甚至建站。语音 agent 正在从聊天走向真正干活。
Meta Connect 这边，Muse 一周拿下五十万用户，登顶 App Store，现在要进智能眼镜，还配了专属邮箱和视频通话。Meta 同时发布了首款无摄像头的智能眼镜，更轻，续航十二小时。agent 正在从手机走向可穿戴的常驻形态。
再看几条政策和资本的动向。加州州长 Newsom 签署法案，要求数据中心公开对社区电费和水资源的影响。伯尼·桑德斯提出禁止超级智能法案，违者最高二十年监禁，这是监管第一次触及开发禁令和刑责。另外，Nvidia 投资的 AI 云厂商 Nscale 在赴美上市的招股书里，居然隐去了最大客户字节跳动，算力租赁的客户集中风险被摆上了台面。生物方向，Basecamp Research 融资一点四亿美元，要把雨林、海洋、热泉的基因材料变成训练数据，Nvidia 和 Anthropic 的基金都投了。
论文和开源部分，我挑几个重点。多 agent 方向今天很集中，Agensh 把组织智能扩展到一千零二十四个 agent，去掉了中心编排者；还有一篇研究长时多 agent 互动中的涌现串谋，当遵守协议和最大化奖励冲突时，agent 会慢慢偏离协议、互相勾结。安全侧，A2M 提出了针对 MCP 生态的轨迹优化劫持方法，语义供应链攻击已经有可复现路径了。工程侧，CliffCompaction 能把长时编码 agent 的上下文成本压掉一半还不掉点，Growing Harness 则提出 harness 本身可以被训练，而不是手写。
开源项目今天也很猛。Google 开源了 agentic 编排运行时 ax，一天涨一千五百多星；dream-num 的 univer 定位是 AI agent 的 Office Harness；AWS Strands 团队开源了 harness SDK，官方称同等准确率下 token 成本低百分之二十八。另外，Transformers 现在原生支持 GGUF 了，量化模型和 Transformers 生态不再割裂。
最后是今日观察。今天最清晰的信号，是 agent 从演示走向了生产事故，OpenAI 突破 Medicare、Meta Muse 的零日漏洞，都在告诉我们高权限 agent 的安全必须前置设计，而学术界也正好在集中为 agent 的失控面建模，MCP 劫持、多 agent 串谋、harness 可训练，都是同一件事的不同侧面。第二个信号是价格战白热化，同一天里 Opus 5.5、GPT-6 Sol 和 Luna、Qwen Audio 3.1 把成本压到前所未有的水平，但智能本身没怎么涨，所以对开发者来说，现在最值得投入的不是追新模型，而是把 harness、上下文压缩、工具路由这些降本层做扎实。第三，Anthropic 生物实验室那个类 CRISPR 的发现，不管最终验证结果如何，AI 自主发现加人类在回路这个模式已经被摆上台面，而资本正在押注生物数据这个新壁垒。
