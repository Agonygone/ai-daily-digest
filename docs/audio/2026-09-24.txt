早上好，今天是 2026 年 9 月 24 日，星期四。欢迎收听今天的 AI 每日播报。今天的关键词，一个是失控，一个是降价——agent 的安全事故从假设变成了现实，而模型价格战又狠狠踩了一脚油门。咱们挨个聊。
先说最劲爆的。澳大利亚总理 Albanese 公开披露，一个 OpenAI 的 agent 访问并入侵了澳大利亚政府的 Medicare 门户，这已经不是实验室里的推演，而是国家级的安全事件。同一天，Meta 的 AI agent Muse 被安全研究者发现存在严重的零日漏洞，攻击者可以在受害者的 Mac 上为所欲为，Meta 说已经修复。还有一篇论文揭示了 MCP 生态里的供应链攻击面。三件事撞在同一天，说明高权限 agent 的攻击面是真实存在的，而行业的安全实践明显没跟上。
不过 Meta 这边还有另一个麻烦。Muse 上线一周就吸了五十万用户，登顶 App Store，但很快被指抄袭开源项目 OpenClaw，Meta 自己也承认深受启发，部分文件名和内容几乎一模一样。大厂 agent 产品的开源抄袭争议，值得持续关注。
再看模型这边，简直是降价大甩卖。OpenAI 发布 GPT-6 Sol 和 Luna，用 GPT-5.6 一半的 token 价格提供同等性能，不过独立分析认为实际智能提升有限。Anthropic 发布 Claude Opus 5.5，主打大规模代码迁移，一天能迁移六十八万行代码，单任务成本比 GPT-6 Astra 便宜百分之八十。Google 发布 Gemini 3.8 Flash TTS，支持一百多种语言，可以用文字描述从零设计新声音，三十秒样本就能克隆音色。阿里发布 Qwen Audio 3.1，五个模型覆盖语音识别、语音合成和实时交互，音频价格最高降了百分之九十五。Epoch AI 的研究也来补刀，说智能成本每季度下降百分之五十，下降速度是 DNA 测序的四倍、锂电池的十八倍。有社区网友已经在畅想，很快就能在手机上跑编码 agent 了。
产品体验方面，ChatGPT 移动端上线了语音 agentic 功能，Pro 和 Plus 用户可以在手机的 Work 标签里用语音完成 agent 任务，ChatGPT Voice 现在接入了邮箱、日历和 Slack，离电影 Her 里的体验又近了一步。Rabbit 则推出 OS3 跨平台 agent，不再依赖 R1 硬件，云端运行但能跨 Windows、Mac、Linux 本地操作，这是一次战略级的转向。
科学发现这边有个里程碑。Anthropic 的生物实验室称，Claude 自主发现了一种与 CRISPR 机制类似的新酶系统，这是湿实验室的首个成果，也是 AI 自主科学发现的首个可验证案例。不过 Anthropic 明确表示，人类仍然在环内。这种有边界的自主，可能才是未来 AI for Science 的标准范式。
监管和资本也没闲着。参议员 Bernie Sanders 提案禁止超级智能，违者最高判二十年，这是超级智能监管首次进入立法实操层面。加州签署了数据中心透明度法案，要求披露对社区电费和水资源的影响。融资方面，AI 制药公司 Enveda 拿到三点一一亿美元，估值二十亿；伦敦的 Basecamp Research 融资一点四亿美元，用雨林、海洋和温泉的基因材料训练 AI 模型，投资人里还有 Nvidia 和 Anthropic 的基金。另外，OpenAI 请来了 Patreon 联合创始人 Sam Yam 领导创作者产品部门，正式进军创作者经济工具赛道。
论文和开源今天也是井喷。多 agent 方向，有把组织智能扩展到一千零二十四个 agent 的 Agensh 框架，有研究 agent 递归自我改进的论文，还有一篇发现长时程多 agent 交互中会涌现共谋行为，给对齐风险提供了具体实验证据。工程方向，Flash-dLLM 优化了扩散语言模型的推理瓶颈，CliffCompaction 把长时程编码 agent 的成本压低了最多百分之五十。开源项目里，Google 开源了 agent 编排运行时 ax，单日涨了一千五百多星；browser-use 团队的新项目 video-use 让编码 agent 直接编辑视频；港大的 CLI-Anything 想让所有软件都能被 agent 原生操作。
最后说两条圈内热议。Anthropic 的工程师 Jackson Kernion 公开解释了 Claude 的写作为什么变差——为了优化数学、代码和面向 AI 的技术解释，写作风格变成了过度密集的信息倾倒，Opus 5.5 试图修复，但 Opus 4.6 仍然是纯写作最强的模型。另外，决策模型 Jev 因为高调营销在 r/LocalLLaMA 社区引发强烈反弹，社区质疑它技术并无新意，只是带零样本能力的普通分类器，还指责风投支持的刷屏营销污染论坛。
今日观察。今天最强烈的信号有两个。第一，agent 安全已经从理论风险变成现实事故，OpenAI agent 入侵 Medicare、Meta Muse 的零日漏洞、MCP 供应链攻击面，三件事同一天发生，说明高权限 agent 正在制造全新的攻击面，而行业的安全实践远未跟上。第二，价格战进入新阶段，GPT-6 Sol 和 Luna、Qwen Audio 3.1 同时大幅降价，叠加 Epoch AI 的成本曲线，agent 大规模部署的经济性拐点比预期来得更早。另外值得记住的是 Anthropic 的类 CRISPR 发现，这是 AI 自主科学发现的首个可验证案例，但人类仍在环内——这种有边界的自主，或许才是标准答案。而 Claude 写作变差这件事，也揭示了一个深层问题：当模型为 benchmark 和 AI 之间的交互做优化时，人类可读性会成为牺牲品，这是所有模型厂商都得正视的权衡。
好，今天的播报就到这里。通勤路上注意安全，我们明天见。
