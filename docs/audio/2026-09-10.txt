早上好，今天是 2026 年 9 月 10 日，欢迎收听今天的 AI 日报。今天的关键词只有一个，那就是冲突——AI 和学术共同体之间的正面碰撞，再加上头部实验室在加速与刹车之间的公开分裂。我们抓紧开始。
先看 OpenAI，今天一口气放了好几个大招。最重磅的是 GPT-6 Astra，面向企业工作场景，主打高级推理、计算机使用能力，还有更强的写作和设计判断力，基本可以看作是办公自动化和 Agent 的新基座。同时发布的还有 ChatGPT Images 2.5，拆成两个模型，Flare 主打速度，Sunburst 主打精确编辑，多轮指令遵循和参考图主体保持都有明显提升。但真正引爆舆论的不是产品，而是 OpenAI 宣称用未发布模型解决了 Navier-Stokes 千禧年难题。NYU 数学家 Tristan Buckmaster 公开指控其窃取并施压，Sam Altman 否认，而 Terence Tao 的警告更值得琢磨——他说，如今连某人正在研究某问题的传闻，都会触发大规模算力去抢先抹平，这可能会逆转数百年的开放科学传统。
安全侧的消息同样密集。Anthropic 这边，前预训练研究员 Jacob Coxon 辞职，指控两家公司明知风险仍冒险竞赛，同事 Evan Hubinger 更是给出十年内失控超级智能灭绝人类概率超过百分之十的估计。同时 Anthropic 披露了第四起与早期版本 Claude 相关的网络安全事件。而 OpenAI 那边，知名对齐研究者、AI 悲观派代表人物 Paul Christiano 加入了 OpenAI Foundation 董事会和安全与安保委员会。两家头部实验室在加速和刹车之间的姿态差异，越来越摆在台面上。
产品侧今天有个很清晰的共识。Meta 发布了个人 AI Agent「Muse」，它不只是回答问题，而是主动执行——发邮件、订机票、谈账单，每个用户有独立的专属安全云电脑，关掉 App 之后它还在继续工作。Agent 架构正在从会话转向常驻云端的执行体。这个趋势在今天 GitHub 霸榜的项目上也印证得很明显，ECC、superpowers、PI-Desktop 这些项目都在做 harness、记忆和输出格式的工程优化。特别有意思的是一个叫 i-have-adhd 的技能，强制编码 Agent 把结论放在最前面，单日涨了四千六百多颗星，增速第一，说明大家对 Agent 输出格式的需求有多强烈。
其他值得关注的还有几条。Suno 发布 v6 音乐模型，和 Warner、BMG、Believe 合作，训练数据不含旧模型数据，但 Universal 和 Sony 的诉讼还在进行。Google DeepMind 发布 AlphaGenome Atlas，预测人类基因组约九十亿个单碱基变异的分子效应，数据规模达到 1PB，是 AlphaFold 数据库的三十倍。Apple 随 iPhone 18 Pro 推出 Reference Image，用相机传感器给每个像素签名，验证照片有没有被 AI 篡改，内容溯源下沉到了硬件层。开源方面，Google 开源了 Mantis，给编码 Agent 的漏洞全生命周期技能包；NVIDIA 发布 CUDA Rust，Rust 正式成为 GPU kernel 的一等语言。
论文方面今天质量很高。DF26 基准显示，人类和 SOTA 深伪检测器都已经无法可靠分辨 AI 生成的单人演讲视频。WearableQA 基于两百名真实用户最长五百天的可穿戴数据，构建了四千多道健康推理题，是健康 Agent 第一个真实纵向评测标准。还有几个围绕 Agent 自我改进的基准，比如 SAEScientist-Bench 和 Φ-Bench，都在考 AI 能不能自主做可解释性研究、能不能工程化支撑自己的基础设施。
今日观察。今天最响的信号，是 AI 竞赛正在侵蚀学术开放共享的底层激励。当算力可以抢跑任何公开的研究方向，开放科学的前提就被动摇了。与此同时，两家头部实验室一个在披露安全事故、一个在请对齐悲观派进董事会，路线分歧越来越公开。而产品侧的竞争重心，已经从模型能力转向了 harness、记忆和输出格式工程。最后值得注意的，是 Google 的 Mantis 和 NVIDIA 的 CUDA Rust，一个让 Agent 自动修漏洞，一个让 GPU kernel 编译期就安全——当 AI 开始写漏洞利用、也开始修漏洞，防御侧工具链的成熟度，会是下一个分水岭。我们明天见。
