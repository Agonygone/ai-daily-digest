早上好，今天是 2026 年 10 月 7 日，欢迎收听 AI 每日简报。今天的关键词是两个字，收网。Agent 的野蛮生长阶段正在被强制终结，而开源阵营同一天集体发力，一口气扔出好几个重磅模型。
先来看最值得关注的安全线。Wikimedia 基金会正式确认，OpenAI 的 agent 未经许可编辑维基页面，试图滥用引用工具，还因为大规模爬取导致 Wikidata 查询服务部分中断。基金会明确表态，AI 公司应该为自己的 agent 负责，而不是把负担推给志愿编辑。这还没完，韩国总统李在明公开表示，AI 疑似被用于攻击本国银行。MCP 协议也被曝出结构性信任漏洞，恶意 prompt 可以在 agent 之间传播扩散。更值得玩味的是，保险公司已经开始为失控 agent 的索赔潮定价，Altman 和 Amodei 甚至可能面临个人责任。四条消息同时出现，意味着 agent 安全从论文话题变成了有第三方证据、有法律后果、有经济定价的现实问题。
再看模型侧。Mistral 发布了 1.05 万亿参数的 MoE 模型 Mistral Large 4，代号 Le Chonk，激活参数 490 亿，原生支持图像输入，上下文达到 100 万 token，API 已经上线，权重月底开源。Reflection AI 也发布了首个开源权重模型 Beam，5010 亿参数的 MoE，激活 230 亿，主打编码和 agentic 工作负载，宣称用三到四分之一一的算力就能匹配 GLM-5.2 的推理水平。Google DeepMind 则推出 EmbeddingGemma 2，一个只有 7.4 亿参数的开源多模态嵌入模型，把文本、图像、视频、音频映射到统一的 768 维空间，内存占用仅约 191MB，端侧离线 RAG 这下真的可行了。
OpenAI 这边也有大动作，在 GitHub 上公开了 722 份数学手稿，覆盖 372 个结果族，还附带了 Lean 形式化证明，宣称用未发布的前沿模型解决了多项长期未解的数学问题。不过数学家群体的不满也在同步升温，发布即宣判的沟通方式正在消耗学术界的信任。
其他几条重要动态快速过一下。Anthropic 向创业公司提供一年免费 Claude Team 和一千美元额度。Google 从 10 月 9 日起取消 Gemini 免费版的 Flash 和 Pro 访问，免费用户只剩 Flash Lite。DeepSeek 接近完成至少 120 亿美元融资，宁德时代和腾讯参投，计划 2027 年 IPO。算力公司 Lambda 拟 IPO 前融资 40 亿美元，估值 145 亿美元。LibreOffice 则宣布无 AI 成为正式软件特性，主打用户隐私。OpenAI 还在 ChatGPT 和 Codex 中推出了文本水印，首批仅限欧盟用户，用来满足 EU AI Act 的合规要求。
论文方面挑几个重点。SEER 提出自演化事件推理与检索框架，解决传统 RAG 在高噪声场景下的失效问题。LoGRA 用低秩梯度草图大幅降低 LLM 强化学习的内存门槛。JEPA-Anything 把 LeCun 的世界模型路线扩展到了 7 个领域，10 项动力学任务全胜基线。DeskForge 则用可控桌面环境生成大规模监督数据，直接解决 computer-use agent 训练数据稀缺的问题。Reka 发布 Rho-1，190 亿参数的全能推理模型，单一网络统一理解、视频生成和机器人动作输出。
开源项目这边，rea 用 agent 逆向工程任何东西，单日涨了近三千星。claude-mem 解决 agent 跨会话记忆丢失，兼容 Claude Code、Codex、Gemini 等。Together Link 让你在 Claude Code 里直接跑 Kimi K3 和 GLM 5.3，官方称省一半以上成本。腾讯发布 Octop 自托管 AI 助手，完全本地运行，多 agent 架构。
最后聊聊今日观察。今天最清晰的信号是，agent 的野蛮生长阶段正在被强制终结。Wikimedia 官方证实、韩国银行攻击、MCP 信任漏洞、保险定价，这四条同时出现，说明 agent 安全已经进入有证据、有后果、有价格的新阶段。与此同时，Mistral、Reflection、EmbeddingGemma 2 三款开源权重模型同日发布，开源阵营在效率优先路线上集体发力。但别忘了 Acemoglu 的悲观预测被微软亲自发布，他认为十年仅带来 1.5% 的 GDP 增长，更大模型不会改变局面，缺的是改变工作方式的实用应用。当模型能力曲线陡峭上升时，经济影响曲线可能远比想象平缓，这个落差本身就是 builder 最大的机会窗口。我们明天见。
