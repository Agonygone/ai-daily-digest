📄 Papers

Google researchers propose RRSI to stop self-improving AI agents from memorizing their tests
Self-improving agents tend to memorize test tasks, causing gains to shrink or vanish on new ones; RRSI lifts scores on unseen benchmarks by up to 4.7 points while using ~30% fewer tokens than an unregularized version.
DeepMind researchers propose "Artificial Symbiotic Intelligence" as alternative to the singularity
Argues general AI won't emerge as a single supermodel but as a network of cooperating agents and humans; what matters most is not model size but the rules and institutions governing collaboration.
Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It
Pretrained transformers use little depth for in-context references (13 base models reliably follow only 1.4-3.6 lines); a rank-8 LoRA at one early layer boosts Qwen3-8B from 15.5% to 99% exact accuracy on 24-line chains.
Honeycomb: Constant-Size Scene Memory Representation for Video World Models
Introduces HexMemory, a low-rank representation storing scene features in a fixed-size memory of six spatial and spatiotemporal planes, solving existing spatial memory's linear growth during generation.
SemanTok: Predictable Semantic Tokens for Efficient Autoregressive Video Generation
Proposes a flexible-length coarse-to-fine tokenizer for video world models, where first coarse tokens carry global semantics and later tokens specify details, balancing fidelity and semantics.
Decoding Looped Transformers Better for (Almost) Free
Introduces LoopCD, a training-free contrastive decoding framework that uses naturally aligned weak-and-strong prediction pairs from each loop to guide token selection, requiring no auxiliary models or external training.
NEEDLE: Backdoor Removal in LLMs via Weight Orthogonalisation
A training-free backdoor removal method that estimates a backdoor direction after trigger identification and orthogonalizes weights, avoiding output distribution shifts on benign prompts seen in existing methods.
Google Research moves federated learning into TEEs; Gboard now trains with externally verifiable differential privacy
Gradient computation moves from phones to attested server-side TEEs, access policies published to Sigstore's Rekor log with reproducibly buildable binaries, enabling external auditing of central differential privacy. Already used in Gboard for English and Japanese next-word prediction.
LOCI: Spatial Linear Memory for Streaming World Models
A hybrid spatial-memory architecture retaining both retrievable past observations and a compact recurrent state, resolving the dilemma between KV caches growing with video length and recurrent memory compressing history.
